LLM 라벨과 코드 랭커 카드 네 장

「러닝화 추천」의 광고 후보 30개를 모델이 하나씩 판정하고, 순위는 코드가 상업 가치와 섞어 정하는 자리를 한 장씩 봅니다. 후보 하나에 라벨 하나, 코드가 섞는 순위, 노출된 광고에만 붙이는 근거, 한 번에 다 맡기면 잘리는 답입니다. 후보의 문장, pCTR, 입찰가, 정답은 설명용 가상 값이고, 모델의 답은 qwen3.5:27b 의 기록입니다.

파랑 = 코드와 정답, 코드가 정한 점수 벽돌색 = 모델의 답 회색 = 노출되지 않거나 읽지 못한 자리 점선 상자 = 시스템 메시지의 정의

LABEL

후보 하나에 라벨 하나

쉽게 말하면 광고 하나를 보여 주고 넷 가운데 하나로 답하게 합니다. 왜 그렇게 봤는지는 이유 코드와 문장 id 로 받습니다.

정답과 맞은 답은 17/30, kappa 는 0.45 입니다. 근거 없는 주장 3개는 모두 policy_risk 로 걸렀고, low 는 한 번도 나오지 않았습니다.

RANK

순위는 코드가 섞는다

쉽게 말하면 모델의 라벨에 가중치를 매기고, 클릭할 확률과 입찰가를 곱해 코드가 순위를 정합니다.

라벨 없이 정한 상위 5개 가운데 4개가 바뀌었습니다. 서연 씨의 a01 은 9위에서 3위로 올라왔습니다.

EVIDENCE

근거는 노출된 것에만

쉽게 말하면 모델은 근거로 문장 번호만 적고, 문장은 코드가 붙입니다. 화면에 나가는 5개에만 붙입니다.

붙이는 근거 문장은 32문장 771자에서 5문장 144자로 줄어듭니다. 노출된 5개의 근거는 모두 s1 입니다.

LISTWISE

한 번에 다 맡기면 잘리는 자리

쉽게 말하면 30개를 한 번에 주면 답이 길어집니다. 답의 길이에 상한을 두면 끝이 잘려 하나도 읽지 못합니다.

상한 없는 run 1 은 읽혔지만 맞은 라벨이 10/30 이었습니다. 400 토큰 상한의 run 2 는 17개 뒤에서 잘렸습니다.

현업에서는 이렇게 씁니다

  • LLM 라벨로 광고 순위를 정할 때는 세 가지를 묻습니다. 라벨 넷이 다 쓰였나, 라벨 없는 순위와 몇 개가 바뀌었나, 잘린 답이 있었나.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 글로 이어 읽으려면 LLM 라벨과 코드 랭커 편에 이 카드들이 절마다 들어 있습니다. 판정을 사람 라벨과 맞춰 본 글은 LLM-as-a-Judge 편입니다.
