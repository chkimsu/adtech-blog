DFS와 백트래킹: 단어 탐색, 부호 선택 트리, 가지치기

재귀 DFS 가 호출하고 돌아오는 순서를 한 단계씩 따라갑니다. 첫 탭은 3×4 판에서 단어를 잇는 탐색(LeetCode 79)에서 칸을 # 로 표시하고 되돌리는 모습, 둘째 탭은 숫자마다 + 와 - 를 고르는 선택 트리(LeetCode 494)의 호출과 반환, 셋째 탭은 같은 트리에서 목표에 닿을 수 없는 노드를 잘라 내는 가지치기입니다. 그래프를 스택과 큐로 순회하는 차이는 DFS vs BFS 에서 따로 봅니다.

한 줄 요약
DFS 는 갈 수 있는 데까지 들어갔다가 막히면 돌아와 다음 길로 가고, 백트래킹은 돌아올 때 바꿔 둔 것을 되돌려 다른 길에서 다시 쓰게 합니다. 같은 판에서 SEE 를 찾으면 dfs 호출이 16번, [1, 1, 1] 에서 합이 3 이 되는 방법을 셀 때 호출이 가지치기 없이 15번, 가지치기하면 7번입니다.
보여 주는 장면과외에서 지훈 씨가 물은 재귀 탐색 장면 셋입니다. 판의 칸을 위, 아래, 왼쪽, 오른쪽 순서로 이어 단어를 만들 때 한 번 쓴 칸을 # 로 바꿔 두고 막히면 원래 글자로 되돌리는 일, 숫자마다 + 와 - 를 고르는 모든 경우를 노드로 그린 선택 트리에서 호출이 내려갔다가 값을 돌려주며 올라오는 일, 그 트리에서 남은 숫자를 모두 써도 목표에 닿지 않는 노드를 더 들어가지 않고 잘라 내는 일을 봅니다. 스택과 큐로 그래프를 순회하는 차이는 DFS vs BFS 데모에서 이어서 봅니다.
목적첫 탭에서는 표시한 칸이 막힌 뒤 되돌려져 다른 길에서 다시 쓰일 수 있다는 것과, 이미 표시한 칸을 만나면 같은 칸을 두 번 쓰지 않고 돌아온다는 것을 확인합니다. 둘째 탭에서는 노드마다 두 자식이 돌려준 개수를 더해 올라오며 루트가 방법의 수를 돌려준다는 것을 확인합니다. 셋째 탭에서는 같은 입력에서 가지치기가 호출 수를 줄이지만 방법의 수는 같다는 것을 확인합니다. 입력은 다섯 가지입니다. 첫 탭은 판 [ABCE, SFCS, ADEE] 에서 단어 SEE, ABCCED, ABCB 이고, 둘째와 셋째 탭은 숫자 [1, 1, 1] 에서 목표 1 과 목표 3 입니다.
결과 읽는 법결과 칸은 첫 탭에서 단어가 판에 있는지(True, False)와 dfs 호출, 막힌 시도, 표시, 되돌리기의 횟수, 둘째와 셋째 탭에서 방법의 수와 호출 수입니다. 보드의 위쪽은 찾는 단어나 숫자 목록이고 아래쪽은 판이나 선택 트리입니다. 파란 테두리가 지금 보는 칸이나 호출, 연한 파란 칸이 표시한 칸이나 쌓인 호출, 진한 파란 칸이 찾은 길이나 목표에 맞은 잎, 붉은 칸이 글자가 달라 막힌 칸, 점선 노드가 잘린 노드입니다. 노드 아래 작은 숫자는 그 호출이 돌려준 개수입니다. 파이썬 코드와 비용은 글에서 이어서 봅니다.
    따라 하는 순서
  1. 탭 단어를 잇는 탐색에서 입력은 단어 SEE 입니다. 「다음 칸」을 두 번 누르면 시작 칸 (1,0) 의 S 를 # 로 바꿨다가 네 방향이 막혀 S 로 되돌린 단계 6 / 21 입니다. 네 번 누르면 (1,3) 의 S 에서 이어진 (0,3) 의 E 가 # 로 바뀌고, 다섯 번 누르면 이 칸이 막다른 길이라 E 로 되돌아옵니다(단계 13 / 21). 「끝까지」를 누르면 결과 칸에 「SEE 있음 (True)」이 나오고 (1,3), (2,3), (2,2) 가 진한 파란색이 됩니다.
  2. 같은 탭에서 입력 목록의 ABCB 를 고르고 「끝까지」를 누르면 「ABCB 없음 (False)」이 나오고 판의 글자가 처음과 같습니다. 단어 ABCCED 는 「끝까지」 뒤 호출 17번입니다.
  3. 탭 부호를 고르는 탐색에서 입력은 [1, 1, 1] 에 목표 1 입니다. 「다음 반환」을 한 번 누르면 루트에서 세 번 내려가 잎 r+++ (합 3)까지 호출하고 목표와 달라 0 을 돌려주는 단계 5 / 30 입니다. 「끝까지」를 누르면 노드 15개가 모두 나오고 맞은 잎 셋이 진한 파란색이며 결과 칸에 「방법 3가지」가 나옵니다.
  4. 탭 가지치기한 탐색에서 입력은 [1, 1, 1] 에 목표 3 입니다. 「다음 반환」을 일곱 번 누르면 「끝까지」와 같은 단계 14 / 14 입니다. 노드는 7개이고 점선 노드 둘이 잘린 노드이며 결과 칸에 「호출 7번(가지치기 없이 15번), 잘린 노드 2개」가 나옵니다. 탭이나 입력을 바꾸면 처음 상태로 돌아갑니다.
