해시 맵: seen 으로 짝 찾기와 이중 for 문

합이 target 인 두 값의 인덱스를 찾는 Two Sum 을 seen 한 번 순회, 이중 for 문, 먼저 다 적는 풀이 세 방식으로 한 단계씩 따라갑니다. 세 방식이 같은 입력에서 몇 번 확인하는지, 어떤 답을 내는지를 나란히 비교합니다.

한 줄 요약
seen 에 지나온 숫자와 인덱스를 적어 두면 짝 확인이 값마다 한 번으로 끝납니다. nums 가 8개이고 target 이 18 일 때 이중 for 문의 비교 28번이 seen 확인 8번으로 줄어듭니다. 다만 적는 순서가 중요해서 nums = [3, 2, 4], target = 6 에서 먼저 모두 적고 확인하면 0번 칸을 두 번 쓴 [0, 0] 이 나옵니다.
보여 주는 장면Two Sum 은 nums 에서 더해서 target 이 되는 서로 다른 두 칸의 인덱스를 돌려주는 문제입니다. 이중 for 문은 두 인덱스의 조합을 하나씩 더해 보고, 해시 맵 seen 은 지나온 값을 「숫자 → 인덱스」로 적어 두었다가 필요한 짝 target - num 이 적혀 있는지 한 번에 확인합니다. 같은 문제를 푸는데 확인하는 횟수가 이중 for 문은 많아야 조합의 수, seen 은 많아야 값의 수라서 nums 가 길어질수록 차이가 커집니다.
목적seen 이 이중 for 문의 비교를 어느 만큼 줄이는지 같은 입력으로 세어 보고, 적는 순서를 바꾸면 틀린 답이 나오는 까닭을 봅니다. 입력은 세 가지입니다. 기본 입력 nums = [2, 11, 7, 15], target = 9 는 답이 앞쪽에 있어 이중 for 문이 2번, seen 이 3번 확인합니다. nums = [4, 9, 1, 7, 12, 3, 10, 8], target = 18 은 답이 맨 뒤에 있어 이중 for 문이 28번(7 + 6 + 5 + 4 + 3 + 2 + 1), seen 이 8번 확인합니다. nums = [3, 2, 4], target = 6 은 3 이 target 의 절반이라 자기 자신이 짝으로 보입니다.
결과 읽는 법결과 칸은 돌려준 답 [i, j] 이고 아랫줄에 같은 입력의 seen 확인 횟수와 이중 for 문 비교 횟수가 나옵니다. 두 횟수의 크기 차이가 seen 이 줄여 준 양입니다. 답이 앞쪽에 있으면 이중 for 문이 더 적을 수도 있으므로 답이 뒤에 있는 입력에서 비교합니다. 먼저 다 적는 풀이 탭의 아랫줄은 횟수 대신 그 답이 맞는지와 순서대로 확인한 뒤 적을 때의 답을 적습니다. 배열의 칸 색은 파란 테두리가 지금 보는 값, 옅은 파란 바탕이 seen 에 적힌 값, 진한 파란 바탕이 찾은 짝, 붉은 바탕이 같은 칸을 두 번 쓴 틀린 답입니다. seen 칸의 「2 → 0」은 숫자 2 가 0번 칸에 있다는 뜻입니다.
    따라 하는 순서
  1. 탭 seen 한 번 순회에서 입력은 nums = [2, 11, 7, 15], target = 9 입니다. 「한 칸」은 동작 하나를 보입니다. 먼저 짝 target - num 이 seen 에 있는지 확인하고, 없으면 다음 「한 칸」에서 num → i 를 seen 에 적습니다. 이번 단계 칸이 방금 한 동작을 문장으로 적습니다.
  2. 「다음 값」은 값 하나의 확인과 적기를 한 번에 합니다. 처음 두 값은 짝 7 과 -2 가 seen 에 없어 2 → 0, 11 → 1 이 적히고, 세 번째 값 7 에서 짝 2 를 찾아 결과 칸에 [0, 2] 가 나옵니다. 「끝까지」는 남은 단계를 한 번에 보이고 「처음」은 첫 상태로 돌아갑니다.
  3. 탭 이중 for 문에서 입력을 nums = [4, 9, 1, 7, 12, 3, 10, 8], target = 18 로 두고 「다음 값」을 누릅니다. i 하나에 대해 j 를 끝까지 비교하고, 「끝까지」를 누르면 답 [6, 7](10 + 8 = 18)과 비교 28번이 나옵니다. 비교한 조합 칸에는 지금 i 로 만든 조합만 보이고, 지금까지 비교한 조합의 수는 그 아래 글에 적힙니다.
  4. 탭 먼저 다 적는 풀이로 바꾸고 입력을 nums = [3, 2, 4], target = 6 으로 고릅니다. 「다음 값」을 한 번 누르면 값 3개가 모두 seen 에 적히고 두 번째 누르면 값 3 의 짝 6 - 3 = 3 이 이미 적혀 있어 [0, 0] 이 나옵니다. 결과 칸의 붉은 [0, 0] 은 0번 칸의 3 을 두 번 쓴 틀린 답이고, 아랫줄에 순서대로 확인한 뒤 적으면 [1, 2] 라고 나옵니다.
  5. 입력 목록에서 다른 입력을 골라 같은 탭에서 다시 눌러 봅니다. 탭이나 입력을 바꾸면 처음 상태로 돌아가고, 탭을 바꿀 때 고른 입력은 그대로 남습니다. 같은 입력을 세 탭에서 차례로 보면 답과 횟수가 어떻게 다른지 나란히 비교됩니다.
