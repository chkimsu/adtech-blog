수아가 새 랭킹 모델의 성적을 지난주 로그로 추정해 검토 자리에 올렸다. 그 자리에서 갈리는 것은 다음 분기 광고비 ₩1,200,000,000을 이 모델에 맡길지 말지다. 검토하던 동료가 질문 하나를 던졌다. 그 확률, 정말 맞습니까.

추정에 쓴 확률은 옛 모델이 그 광고를 고를 확률이다. 수아는 로그에 적힌 값을 그대로 믿고 분모에 넣었다. 지난주 탐색 설정이 기록과 달랐다면 그 분모가 어긋나고, 추정치와 예산 결정도 같이 어긋난다.

**재료를 하나 더 쓰면 어떨까?** 우리는 광고가 클릭될 확률을 예측하는 모델을 이미 갖고 있다. 광고를 띄우기 전에 순위를 매기는 pCTR 모델이 바로 그것이다.

확률과 예측 모델을 겹치는 방법에 이름이 있다. **이중 강건**(doubly robust)이다. 둘 중 하나만 맞아도 값이 진짜에 붙는다는 뜻이고, 이 성질 하나가 보고서를 승인할지 되돌릴지를 가른다.

> **한 줄 요약:** 예측 모델로 답을 먼저 깔고, 확률의 역수 가중은 그 예측이 빗나간 몫에만 건다. 그러면 확률과 예측 모델 중 하나만 맞아도 치우침이 사라진다. 대신 흔들림은 거의 안 줄고, 예측 모델을 평가에 쓸 로그로 학습하면 값이 조용히 기운다.

> 이 글은 [Off-Policy Evaluation](post.html?id=offpolicy-evaluation)에서 이어진다. 옛 정책·새 정책·성향점수·확률의 역수로 세기는 거기서 나온 말이다. 절 제목의 `[무대: 열린 RTB]`는 남의 거래소에 입찰만 넣는 자리를 뜻한다. **닫힌 생태계**는 우리가 경매를 직접 돌리는 자리이고, **공통**은 두 자리 모두라는 표시다.

---

## 1. 재료가 하나 더 있다

**지금까지 쓴 재료는 확률 하나였다. 광고가 클릭될 확률을 예측하는 모델을 재료로 하나 더 쓸 수 있고, 그 비용은 거의 없다.**

지난주 로그로 새 정책을 채점하는 계산은 재료 하나로 돈다. 옛 정책이 그 광고를 고를 확률, 곧 **성향점수**다. 두 정책이 같은 광고를 고른 건을 그 확률의 역수만큼 크게 세면, 온라인 A/B 비용을 안 쓰고도 버려진 건까지 세어진다.

이 계산은 성향점수를 그대로 믿는다. 분모에 들어가는 값이라 조금만 틀려도 결과가 크게 움직인다. 지난주 탐색 비율이 기록과 달랐다면 추정치가 조용히 기울고, 그 위에서 예산 결정이 내려진다.

재료가 하나 더 있다. 어떤 광고를 띄우면 클릭될 확률이 얼마인지 예측하는 모델이다. 논문에서는 **보상 모델**이라 부르는데, 보상은 그 광고를 띄워 우리가 얻는 결과를 뜻한다. 이 글에서는 클릭 여부이고, 클릭이면 1 아니면 0이다.

그런 모델은 이미 갖고 있다. 광고를 띄우기 전에 순위를 매기는 pCTR 모델이 바로 그것이라, 재료를 하나 더 쓰는 비용이 거의 들지 않는다.

예측 모델만으로 채점할 수도 있다. 새 정책이 고를 광고의 예측을 전부 평균 내면 끝이라, 이 방법을 **예측만 쓰기**(DM, direct method)라 부른다. 로그의 실제 결과를 안 쓰니 모델이 틀리면 그대로 틀리고, 그 오차가 예산 결정에 실린다.

| 방법 | 쓰는 재료 | 확률이 틀리면 | 예측 모델이 틀리면 |
|---|---|---|---|
| 예측만 쓰기 | 예측 모델 | 영향 없다 | 그대로 틀린다 |
| 확률의 역수로 세기 | 성향점수 | 그대로 틀린다 | 영향 없다 |
| 이중 강건 | 둘 다 | 예측 모델이 맞으면 버틴다 | 확률이 맞으면 버틴다 |

표의 마지막 줄이 이 글의 주제다. 두 재료를 겹쳐 두면 하나가 틀려도 다른 하나가 받친다. 어느 쪽이 맞을지 미리 알 수 없는 자리에서 이 성질이 배포 승인과 중단을 가른다.

---

## 2. 예측을 먼저 깔고, 빗나간 몫에만 가중한다

**계산은 두 단계다. 새 정책이 고를 광고의 예측을 다 더한 다음, 겹친 건에서 예측이 빗나간 만큼만 확률의 역수로 더한다.**

첫 단계는 예측만 쓰기와 똑같다. 새 정책이 고를 광고의 예측을 요청마다 더해 평균을 낸다. 여기까지는 로그의 실제 클릭을 한 번도 안 보고, 비용은 예측 한 번씩이 전부다.

둘째 단계가 로그를 쓴다. 두 정책이 같은 광고를 고른 건에서 실제 클릭과 예측의 차이를 구해, 그 차이만 확률의 역수만큼 크게 더한다. 뒤 단계가 앞 단계의 오차를 메운다.

중요한 것은 뒤 단계가 무엇에 가중하느냐다. 결정을 흔드는 큰 가중치가 클릭이 아니라 **잔차**(residual, 실제 결과에서 예측을 뺀 값)에 붙는다. 예측 모델이 잘 맞으면 잔차가 작아지고, 큰 가중치가 곱해질 값 자체가 작아진다.

이 방법을 **이중 강건**(DR, doubly robust)이라 부른다. 재료가 둘인데 그중 하나만 맞아도 값이 산다는 뜻에서 붙은 이름이다.

아래 코드가 네 경우를 다 만든다. 성향점수가 맞거나 틀리고, 예측 모델이 맞거나 틀린다. 틀린 성향점수는 지난주 탐색 비율을 10%가 아니라 20%로 잘못 알고 있는 경우다.

틀린 예측 모델은 후보를 구분하지 못하고 지면 평균만 내놓는다. 로그를 지어내는 부분까지 안고 있어 그대로 복사해 돌려도 된다.

```python
# DR(이중 강건) — 보상 모델과 성향점수 중 하나만 맞아도 값이 산다.
# 넷을 다 만들어 본다: (성향점수 맞음/틀림) x (보상 모델 맞음/틀림)
import math, random
K, EPS, TAU = 8, 0.10, 0.0014
SLOTS = [("main_top", 2600, 0.024, 0.044, 0.000), ("search_top", 1400, 0.016, 0.032, 0.003),
         ("feed_mid", 3100, 0.007, 0.018, 0.010), ("feed_low", 2000, 0.004, 0.012, 0.014),
         ("detail_side", 900, 0.003, 0.009, 0.018)]

def build_log(seed=7):                          # 2절과 같은 함수다
    random.seed(seed); log = []
    for name, n, lo, hi, bonus in SLOTS:
        for _ in range(n):
            base = [random.uniform(lo, hi) for _ in range(K)]
            ctr = [b + bonus * (1 if random.random() < 0.2 else 0) for b in base]
            old_s = [b + random.gauss(0, 0.004) for b in base]
            new_s = [c + random.gauss(0, 0.002) for c in ctr]
            m = max(old_s); ex = [math.exp((s - m) / TAU) for s in old_s]; Z = sum(ex)
            p = [(1 - EPS) * (x / Z) + EPS / K for x in ex]
            u, acc, a = random.random(), 0.0, K - 1
            for i, pi in enumerate(p):
                acc += pi
                if u <= acc: a = i; break
            log.append((name, ctr, p, a, 1 if random.random() < ctr[a] else 0,
                        max(range(K), key=lambda i: new_s[i])))
    return log

MEAN = {n: (lo + hi) / 2 + 0.2 * bonus for n, _, lo, hi, bonus in SLOTS}   # 지면 평균 CTR
pool = []      # (진짜 성향, 잘못 기록된 성향, 진짜 CTR, 지면 평균으로 뭉갠 예측)
for name, ctr, p, a, r, e in build_log():
    soft = (p[e] - EPS / K) / (1 - EPS)                # softmax 성분만 되꺼낸다
    pool.append((p[e], 0.80 * soft + 0.20 / K, ctr[e], MEAN[name]))
N = len(pool)
V = sum(c for _, _, c, _ in pool) / N
DM = {1: sum(c for _, _, c, _ in pool) / N, 0: sum(q for _, _, _, q in pool) / N}

est = {(tp, tq): {"ips": [], "dr": []} for tp in (1, 0) for tq in (1, 0)}
for wk in range(400):
    rng = random.Random(1000 + wk)
    rows = [(pe, pw, ce, qm, 1 if rng.random() < ce else 0)
            for pe, pw, ce, qm in pool if rng.random() < pe]     # 겹친 건만 남는다
    for (tp, tq), box in est.items():
        ips = corr = 0.0
        for pe, pw, ce, qm, r in rows:
            ph = pe if tp else pw                                # 우리가 믿는 성향점수
            q = ce if tq else qm                                 # 보상 모델의 예측
            ips += r / ph
            corr += (r - q) / ph                                 # DR은 잔차에 가중한다
        box["ips"].append(ips / N)
        box["dr"].append(DM[tq] + corr / N)

def sd(v):
    mu = sum(v) / len(v)
    return (sum((x - mu) ** 2 for x in v) / (len(v) - 1)) ** 0.5

print(f"새 정책의 진짜 값 = {V:.3%}   (400주 평균)\n")
print(f"{'성향점수':<10}{'보상 모델':<12}{'DM':>9}{'IPS':>9}{'DR':>9}{'IPS 편차':>10}{'DR 편차':>10}")
for (tp, tq) in ((1, 1), (1, 0), (0, 1), (0, 0)):
    b = est[(tp, tq)]
    print(f"{'맞음' if tp else '틀림':<10}{'맞음' if tq else '틀림':<12}{DM[tq]:>9.3%}"
          f"{sum(b['ips'])/400:>9.3%}{sum(b['dr'])/400:>9.3%}"
          f"{sd(b['ips']):>10.3%}{sd(b['dr']):>10.3%}")

# 출력:
# 새 정책의 진짜 값 = 2.807%   (400주 평균)
#
# 성향점수      보상 모델              DM      IPS       DR    IPS 편차     DR 편차
# 맞음        맞음             2.807%   2.776%   2.775%    0.809%    0.806%
# 맞음        틀림             1.980%   2.776%   2.774%    0.809%    0.805%
# 틀림        맞음             2.807%   2.442%   2.797%    0.526%    0.521%
# 틀림        틀림             1.980%   2.442%   2.671%    0.526%    0.521%
```

| 성향점수 | 예측 모델 | 예측만 쓰기 | 확률의 역수로 세기 | 이중 강건 |
|---|---|---|---|---|
| 맞음 | 맞음 | 2.807% | 2.776% | 2.775% |
| 맞음 | **틀림** | **1.980%** | 2.776% | 2.774% |
| **틀림** | 맞음 | 2.807% | **2.442%** | 2.797% |
| **틀림** | **틀림** | **1.980%** | **2.442%** | 2.671% |

새 정책의 진짜 값은 2.807%다. 굵게 칠한 칸이 재료가 틀린 자리이고, 맨 오른쪽 열만 따라 읽으면 된다.

둘째 줄은 예측 모델이 틀린 경우다. 예측만 쓰면 1.980%로 크게 빗나가는데, 이중 강건은 2.774%로 버틴다. 성향점수가 맞았기 때문이다.

셋째 줄은 반대다. 성향점수가 틀렸으니 확률의 역수로 세기가 2.442%로 낮게 나온다. 그런데 이중 강건은 2.797%로 진짜 값 옆에 붙어 있다. 이번에는 예측 모델이 맞았기 때문이다.

같은 로그, 같은 재료인데 어느 쪽이 틀렸느냐에 따라 두 방법 중 하나는 반드시 빗나간다. 이중 강건만 두 경우 모두에서 살아남는다. 후보 모델을 거를 때 순위가 뒤집히면 예산이 엉뚱한 모델로 가니, 배포 결정을 이 값 위에 올릴 수 있다는 뜻이다.

## 3. 왜 하나만 맞아도 되나

**치우침이 두 오차의 곱으로 적힌다. 한쪽이 0이면 곱도 0이라 치우침이 사라진다.**

표의 결과가 우연이 아니라는 것은 치우침을 정리해 보면 드러난다. 이 방법의 치우침은 두 값의 곱으로 적힌다. 앞은 성향점수가 얼마나 틀렸나이고, 뒤는 예측 모델이 얼마나 틀렸나다.

성향점수가 맞으면 앞의 값이 0이 되고, 예측 모델이 맞으면 뒤의 값이 0이 된다. 어느 쪽이든 곱이 0이니 치우침이 사라지고, 그 값으로 배포를 결정할 수 있다. 이것이 표 둘째 줄과 셋째 줄에서 실제로 일어난 일이고, 이름에 '이중'이 붙은 이유다.

곱이라는 사실은 실무에서 더 쓸모가 있다. 성향점수가 10% 틀리고 예측 모델이 10% 틀려도, 치우침은 두 오차의 곱이라 훨씬 작은 자리에 머문다.

그래서 어느 한쪽을 완벽하게 만들려고 사람과 시간을 쏟는 것보다 **둘 다 웬만하게 만드는 편이 싸다.** 성향점수를 정확히 남기는 데는 로그 스키마 변경과 탐색 비용이 들고, 예측 모델을 정확히 맞추는 데는 학습과 검증 비용이 든다. 예산이 한정돼 있다면 양쪽에 나눠 쓰는 쪽이 낫다는 뜻이다.

표의 넷째 줄이 둘 다 틀린 경우다. 이중 강건도 2.671%로 진짜 값보다 4.8% 낮다. 그래도 1.980%나 2.442%보다는 가까운데, 두 오차가 서로를 부분적으로 덮기 때문이다.

:::deep 더 깊이 — 식과 치우침

식으로 쓰면 이렇다. $w_i$는 확률의 역수로 세기에서 쓴 가중치와 같고, $\hat{q}$는 예측 모델이다.

$$\hat{V}_{\mathrm{DR}} = \frac{1}{n}\sum_i \Bigl[\, \hat{q}\bigl(x_i, \pi_e(x_i)\bigr) + w_i\,\bigl(r_i - \hat{q}(x_i, a_i)\bigr) \Bigr]$$

앞항이 예측만 쓰기이고 뒷항이 확률의 역수로 세기다. 뒷항이 클릭 대신 잔차에 가중하는 점만 다르다.

치우침을 정리하면 이렇다. $p$는 진짜 성향점수, $\hat{p}$는 우리가 믿는 값, $q$는 진짜 기대 보상이다.

$$\mathrm{Bias}(\hat{V}_{\mathrm{DR}}) = E\left[\left(1 - \frac{p}{\hat{p}}\right)\bigl(\hat{q} - q\bigr)\right]$$

두 괄호의 곱이라는 점이 전부다. 앞 괄호는 성향점수가 맞으면 0이 되고, 뒤 괄호는 예측 모델이 맞으면 0이 된다.
:::

### 성향점수가 남의 손에 있을 때 [무대: 열린 RTB]

외부 거래소에 입찰을 넣는 DSP에서는 성향점수가 두 항의 곱이다. 우리 정책이 그 광고를 고를 확률과, 그 입찰이 경매를 통과할 확률이다. 뒤 항은 관측되지 않아 모델로 추정해야 한다.

그래서 이 무대의 성향점수는 구조적으로 부정확하다. 확률 하나에만 기대면 표 셋째 줄처럼 낮게 나오고, 그 숫자로 예산을 줄이면 멀쩡한 캠페인을 중단하게 된다.

담장 안에서 경매를 직접 돌린다면 사정이 낫다. 확률을 남길지가 우리 로깅 결정이기 때문이다. 다만 로깅이 부실했던 지난 기간을 다시 채점할 때는 같은 문제가 생긴다.

---

## 4. 대신 흔들림은 안 줄고, 학습 로그를 갈라야 한다

**이중 강건은 치우침을 막지 흔들림을 막지 않는다. 그리고 예측 모델을 평가에 쓸 로그로 학습하면 값이 조용히 기운다.**

한 가지 기대는 접어야 한다. 코드 출력의 마지막 두 열을 보면 주마다 흔들리는 폭이 0.809%에서 0.806%로 사실상 같아, 구간은 그대로 넓다. **여기서 이중 강건은 흔들림을 거의 줄이지 못한다.**

이유는 보상이 0과 1뿐이기 때문이다. 클릭이 드물어 대부분의 건에서 실제 결과가 0이고 예측도 0에 가깝다. 그러면 잔차가 클릭 여부와 거의 같아져, 흔들림도 그대로 남는다.

이득은 보상이 연속인 지표에서 커진다. 클릭 대신 전환 매출이나 체류 시간을 재면 예측이 실제 값 가까이 붙고 잔차가 작아진다. 매출을 지표로 쓰는 캠페인 평가에서 더 값을 한다.

흔들림은 따로 줄여야 한다. 가중치에 상한을 걸고 가중치 합으로 나누는 손질을 얹으면 된다. 대신 값이 내려가는 비용을 같이 치른다([Off-Policy Evaluation](post.html?id=offpolicy-evaluation) 4절).

### 예측 모델은 평가에 쓸 로그로 학습하면 안 된다

주의가 하나 더 있다. 위 성질이 성립하려면 예측 모델이 이 로그로 학습된 것이 아니어야 한다. 같은 데이터로 학습하고 평가하면 잔차가 인위적으로 작아지기 때문이다.

잔차가 작아지면 둘째 단계가 거의 아무것도 안 더한다. 그러면 값이 예측만 쓰기 쪽으로 조용히 기울고, 표 둘째 줄이 보여 준 안전장치가 사라진다.

실무에서는 로그를 시간으로 가르기로 결정한다. 앞 기간으로 예측 모델을 학습하고 뒤 기간으로 평가한다. 이 한 줄을 안 지키면 승인 회의에 올라가는 숫자가 예측 모델의 자기 채점이 되고, 그 결정에 걸린 예산만큼이 위험해진다.

정리하면 이 방법을 쓸지는 재료 상태로 결정한다. 성향점수를 정확히 남겼다면 확률의 역수로 세기만으로 충분하고, 어느 쪽도 확신할 수 없을 때 이 방법을 얹는다.

## 한눈 정리와 헷갈리기 쉬운 점

세 방법을 한 표로 놓으면 고르는 기준이 분명해진다. 재료 상태가 곧 결정 기준이고, 흔들림 칸이 전부 비슷하다는 점을 같이 봐야 한다.

| 방법 | 쓰는 재료 | 치우침 | 흔들림 | 언제 쓰나 |
|---|---|---|---|---|
| 예측만 쓰기 | 예측 모델 | 모델이 틀리면 크다 | 작다 | 로그에 확률이 아예 없을 때 |
| 확률의 역수로 세기 | 성향점수 | 확률이 맞으면 없다 | 크다 | 확률을 우리가 정확히 남겼을 때 |
| 이중 강건 | 둘 다 | 하나만 맞으면 없다 | 확률의 역수로 세기와 비슷 | 확률이 미덥지 않을 때 |

### 헷갈리기 쉬운 점

- **이중 강건은 흔들림을 줄이는 방법이 아니다.** 치우침을 막는 방법이다. 흔들림은 가중치 상한과 가중치 합으로 나누기로 따로 줄이고, 그 손질은 값이 깎이는 비용을 치른다.
- **예측 모델을 평가에 쓸 로그로 학습하면 안 된다.** 잔차가 인위적으로 작아져 값이 예측 쪽으로 기운다. 앞 기간으로 학습하고 뒤 기간으로 평가하도록 기간을 가른다.
- **둘 다 틀리면 이 방법도 틀린다.** 표 넷째 줄이 그 경우다. 다만 두 오차의 곱이라 한쪽만 쓰는 것보다 가까워서, 순위로 거르는 결정에는 쓸 수 있다.
- **보상이 클릭 여부일 때는 이득이 작다.** 잔차가 클릭 여부와 거의 같아지기 때문이고, 전환 매출처럼 이어지는 지표에서 이득이 커진다.
- **예측 모델이 잘 맞는다는 말은 순위를 잘 매긴다는 뜻이 아니다.** 예측한 확률의 크기가 실제 비율과 맞아야 하고, 순위만 좋은 모델은 잔차를 못 줄인다.
