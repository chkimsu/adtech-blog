비용, 캐시, 비결정성 카드 네 장

지훈 씨가 하루 100만 요청의 값을 센 길을 카드 네 장으로 봅니다. 요청 한 건의 토큰 셋을 가상 단가로 세고, 시스템 메시지를 캐시에서 읽으면 얼마가 깎이는지 봅니다. 끝 카드는 같은 입력을 10번 물은 답입니다. 단가와 문제는 가상 데이터입니다.

파랑 = 입력 토큰과 temperature 0 벽돌색 = 출력 토큰과 temperature 0.7 먹색 = 요청과 문제 회색 = 캐시에서 읽은 몫 점선 상자 = 가상 값 (단가)

TOKENS

요청 한 건의 토큰 셋

쉽게 말하면 요청 한 건은 시스템 메시지, 사용자 메시지, 출력의 세 덩이로 값을 냅니다.

큰 모델 한 건은 7.80원, 그중 출력 150 토큰이 3.00원입니다.

CACHE

캐시가 깎는 몫

쉽게 말하면 요청마다 같은 시스템 메시지를 캐시에서 읽으면 그 몫만 0.1배로 셉니다.

캐시 100% 면 큰 모델 하루 값은 4,200,000원, 원래의 54% 입니다.

DAILY

하루 100만 요청의 값 셋

쉽게 말하면 같은 요청 100만 건을 세 경우로 세어 하루와 한 달 값을 나란히 둡니다.

하루 720,000원, 7,800,000원, 4,200,000원이고 한 달은 30배입니다.

VARIANCE

같은 입력 10번의 답

쉽게 말하면 문제 다섯을 temperature 0 과 0.7 로 10번씩 묻고, 서로 다른 답의 수를 셉니다.

temperature 0 은 50개가 글자까지 같았고, 0.7 은 steps 42/45 회차가 바뀌었습니다.

현업에서는 이렇게 씁니다

  • 모델을 붙이기 전에 요청 한 건의 토큰 셋과 하루 요청 수로 값을 먼저 셉니다.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 글로 이어 읽으려면 비용, 캐시, 비결정성 편에 이 카드들이 절마다 한 장씩 들어 있습니다. 바로 앞 이야기는 LLM-as-a-Judge 편입니다.
