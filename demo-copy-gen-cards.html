광고 카피 생성 카드 네 장

광고주 자산 텍스트로 카피를 쓰고, 카피마다 기댄 구절을 옮겨 적게 한 뒤 코드 게이트 넷이 거르는 자리를 한 장씩 봅니다. 자산에서 인용, 카피 후보 다섯, 게이트 넷, 생성 없음도 정상 답입니다. 자산 텍스트는 설명용 가상 값이고, 모델의 답은 qwen3.5:27b 의 기록입니다.

파랑 = 자산 텍스트와 게이트를 지난 카피 벽돌색 = 모델의 답 회색 = 게이트에 걸리거나 카피를 쓰지 않은 자리 점선 상자 = 시스템 메시지와 게이트의 조건

QUOTE

자산에서 인용

쉽게 말하면 카피를 쓸 때 기댄 구절을 상품 설명에서 그대로 옮겨 적게 합니다. 코드는 그 구절이 설명 안에 있는지 글자로 봅니다.

x01 의 카피 5개는 quote 를 자산의 네 문장에서 옮겼고, 넷째 문장은 두 카피가 앞뒤로 나눴습니다. 셋은 quote 와 글자까지 같습니다.

GENERATE

카피 후보 다섯

쉽게 말하면 자산 하나를 주면 모델이 카피를 5개까지 쓰고, 카피마다 기댄 구절을 붙여 JSON 한 줄로 돌려줍니다.

답 10개가 모두 읽혔고, 사실을 적은 자산 8개가 카피를 5개씩, 모두 40개 냈습니다.

GATES

게이트 넷

쉽게 말하면 카피를 정해 둔 규칙 넷에 차례로 넣고, 처음 걸린 규칙에서 뺍니다. 규칙은 모두 코드입니다.

카피 40개 가운데 35개가 남았습니다. 걸린 5개는 모두 근거 게이트였고, quote 의 숫자 뒤 공백이 자산과 달랐습니다.

NONE

생성 없음도 정상 답

쉽게 말하면 쓸 사실이 없는 글에는 카피를 지어내지 않고, 생성 없음으로 답하게 합니다.

얇은 자산 2개는 no_generation 으로 왔고, 답은 12 토큰이었습니다. 사실을 적은 8개는 모두 ok 였습니다.

현업에서는 이렇게 씁니다

  • 모델에게 광고 카피를 쓰게 할 때는 세 가지를 묻습니다. 카피마다 근거 구절을 받았나, 구절과 숫자를 코드가 자산과 대조하나, 생성 없음을 정상 답으로 받나.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 글로 이어 읽으려면 광고 카피 생성 편에 이 카드들이 절마다 들어 있습니다. 답의 값을 검색한 조각과 대조한 글은 RAG 편입니다.
