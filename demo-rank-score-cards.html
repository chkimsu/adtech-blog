위치 1 추론과 LTR 카드 12장

두 문제는 같은 데로 이어집니다. 점수의 순서는 맞는데 크기가 틀립니다. 앞 여섯 장은 서빙 때 모든 후보를 1위로 두고 pCTR 을 낼 때이고, 뒤 여섯 장은 같은 검색 안의 쌍으로 학습할 때입니다. 숫자는 글의 가상 데이터입니다.

파랑 = 광고와 맞는 값 벽돌색 = 틀리거나 의심스러운 값 먹색 = 모델과 랭커 회색 = 위치 효과와 사람이 남긴 기록 점선 = 모르는 것, 짐작 점 = 오가는 요청과 점수

POSITION IN TRAINING

학습 때는 위치를 압니다

쉽게 말하면 노출 로그에 광고가 몇 위에 나왔는지 적혀 있어서, 모델이 광고 품질과 위치 효과를 나눠 배웁니다.

B 는 3.0% 만 클릭됐지만 모델은 이것을 품질 4.0% 와 2위 위치 효과 0.75 로 나눠 배웁니다. 위치를 빼고 학습하면 B 가 실제보다 나쁜 광고로 배워집니다.

POSITION AT SERVING

서빙 때는 위치를 모릅니다

쉽게 말하면 순서를 정해야 위치가 생기는데, 순서를 정하려면 점수가 필요합니다. 그래서 모든 후보를 1위로 두고 점수를 묻습니다.

모두 같은 1위를 가정하니 비교는 공평합니다. 점수 5.0%, 4.0%, 3.0% 로 순서 A, B, C 는 맞게 나옵니다.

INFLATED SCORES

그래서 값이 부풉니다

쉽게 말하면 점수는 1위 기준인데 B 는 2위에, C 는 3위에 갑니다.

B 는 1.3배, C 는 2배 부풀어 나옵니다. 순서를 정할 때는 상관없지만 예상 클릭, 예상 매출, 광고비처럼 크기를 쓰는 계산에서는 틀립니다.

MULTIPLY BY POSITION

정해진 위치의 효과를 곱합니다

쉽게 말하면 순서를 정할 때는 1위 점수를 그대로 쓰고, 돈을 계산할 때는 정해진 위치의 효과를 곱해 씁니다.

B 는 2위에 갔으니 4.0% × 0.75 = 3.0% 로 예상 클릭과 광고비를 셉니다.

WHEN ORDER FLIPS

순서가 바뀌기도 합니다

쉽게 말하면 광고마다 위치 효과가 다르면, 1위를 가정한 순서와 실제 위치의 순서가 다를 수 있습니다.

둘 다 1위라면 A 가 앞서지만 둘 다 3위라면 C 가 앞섭니다. 피처끼리 곱해 배우는 DCN 같은 모델은 이런 위치와 광고의 조합을 배웁니다.

NEVER AT THE TOP

1위에 가 본 적 없는 광고

쉽게 말하면 늘 아래에만 나온 광고 D 를 1위로 가정하면, 모델은 본 적 없는 경우를 짐작합니다.

학습 데이터의 1위는 기존 랭킹이 올린 광고뿐이라 D 의 1위 점수는 짐작입니다. 실제보다 훨씬 높게 나오기도 합니다.

POINTWISE VS PAIRWISE

배우는 문제가 다릅니다

쉽게 말하면 pointwise 는 광고마다 눌렸는지를 맞히고, pairwise 는 같은 검색 안에서 어느 광고가 더 눌릴 만한지를 맞힙니다.

같은 검색 한 번이 pointwise 로는 3줄, pairwise 로는 2쌍이 됩니다.

NO SCALE

점수의 크기를 배우지 않습니다

쉽게 말하면 pairwise 손실은 두 점수의 차이만 봅니다. 모든 점수에 같은 값을 더해도 손실이 그대로입니다.

차이가 똑같이 2 인 두 모델은 손실도 같지만, 확률로 바꾸면 A 가 88% 와 50% 로 다릅니다.

TIMES THE BID

입찰가와 곱하면 뒤집힙니다

쉽게 말하면 광고 순위는 입찰가 × 클릭 점수입니다. 다른 검색에서 학습된 광고끼리는 점수 크기가 맞춰진 적이 없습니다.

맞는 크기라면 Y 가 24 로 1위인데, X 의 점수가 2% 대신 3% 로 나오면 X 가 30 으로 1위가 됩니다.

CLICKED SEARCHES ONLY

클릭이 난 검색만 씁니다

쉽게 말하면 쌍을 만들려면 눌린 광고와 안 눌린 광고가 한 검색에 함께 있어야 합니다.

검색 100번 중 5번만 쌍을 만들고 95번은 버립니다. 학습은 빨라지지만 버린 검색에만 나온 광고는 배우지 못합니다.

POSITION IN PAIRS

쌍에 위치가 섞입니다

쉽게 말하면 2위를 누른 사람은 1위를 보고 지나간 것이 확실하지만, 3위는 아예 안 봤을 수 있습니다.

B > A 는 믿을 만한 쌍이고, B > C 는 광고가 아니라 위치의 차이를 배울 수 있는 쌍입니다.

DEEP SEARCHES WEIGH MORE

광고가 많은 검색이 더 세게 배웁니다

쉽게 말하면 광고 6개 검색의 클릭 하나는 쌍 5개가 되고, 광고 2개 검색의 클릭 하나는 쌍 1개가 됩니다.

같은 클릭 하나가 5배 다르게 들어갑니다. 경쟁이 센 검색을 세게 배우는 장점이자, 그쪽으로 기우는 단점입니다.

현업에서는 이렇게 씁니다

  • 순서를 정하는 점수와 돈을 계산하는 점수를 나눠 봅니다. 위치 1 점수는 줄 세우기에 쓰고, 예상 클릭과 광고비에는 정해진 위치의 효과를 곱합니다.
  • 오프라인 지표는 점수가 어디에 쓰이는지부터 보고 고릅니다. 입찰가와 곱하는 점수라면 요청 단위 AUC 만으로는 부족하고, 전체 AUC 와 예측 합 대비 실제 합을 같이 봅니다.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 이어서 볼 것은 글 Position 1 추론과 Pairwise LTR과, 학습 쪽 보정을 다룬 Position Bias 글입니다.
