지훈 씨는 [행동 시퀀스 Attention](post.html?id=behavior-sequence-attention) 글을 읽고 attention 이 무엇을 하는지는 알게 됐습니다. 광고와 관련 있는 행동에 큰 가중치를 주고 더하는 계산입니다. 그런데 DIN 논문의 모델 그림을 펴 보니 상자가 많았습니다. 그 계산이 모델의 어느 상자에 들어가는지, 나머지 상자는 무엇을 하는지가 한눈에 들어오지 않았습니다.

같이 일하는 사람은 「DIN 은 가변 길이를 잘 풀었다」고 했습니다. 지훈 씨는 임베딩이 사람마다 길이가 다르다는 뜻인지부터 헷갈렸습니다.

**DIN 에서 attention 은 모델의 어느 층에 들어가고, 길이가 다른 것은 정확히 무엇인가요?**

답은 층 일곱 개짜리 그림 한 장에 있습니다. attention 은 그 가운데 두 층, 행동마다 가중치를 매기는 층과 가중치를 곱해 더하는 층에만 들어갑니다. 나머지 다섯 층은 행동을 합이나 평균으로 묶던 이전 모델과 같습니다. 길이가 사람마다 다른 것은 임베딩이 아니라 행동의 개수이고, 두 층이 그것을 고정 길이 벡터 하나로 줄입니다.

> **한 줄 요약:** DIN 은 입력, 임베딩, activation unit, 가중합, 이어 붙이기, MLP, 출력의 일곱 층입니다. attention 은 activation unit 과 가중합 두 층뿐이고, 합이나 평균을 내던 자리를 바꾼 것입니다. 행동 하나의 임베딩은 고정 길이이고, 사람마다 다른 것은 행동의 개수입니다. 결과인 관심 벡터도 고정 길이지만 광고마다 다르게 나와서, 고정 길이 벡터 하나에 여러 관심을 담지 못하던 병목을 풉니다.

> **골라 읽는 법** — 절이 6개인 글입니다. 1절 앞에 이 글의 예시를 푼 표가 먼저 있습니다.
>
> - 모델 전체 그림 → 1절
> - 가변 길이가 무엇의 길이인가 → 2절
> - 가중치가 어떻게 나오나 → 3~4절
> - 가중치의 합이 1 이 아닌 까닭과 pCTR 까지 → 5~6절

이 글의 행동과 광고, 숫자는 전부 설명을 위한 가상 값이고 행동 시퀀스 Attention 글과 같습니다. 그림 속 색은 셋입니다. 파랑은 민지 씨의 행동, 벽돌색은 지금 채점하는 광고, 먹색은 가중치와 사용자 벡터입니다. 점선 칸이 attention 이 들어가는 두 층입니다. 계산은 두 무대가 같아서 글 전체를 공통으로 읽으면 됩니다.

맨 위 입력은 네 묶음입니다. 나이대 같은 사용자 정보, 행동 기록, 지금 채점하는 후보 광고, 시간대나 지면 같은 맥락입니다. 둘째 층 임베딩은 상품 번호, 카테고리 번호 같은 번호를 벡터로 바꿉니다. 행동 넷은 각자 4칸 벡터 하나가 됩니다.

셋째 층이 activation unit 입니다. 행동 하나와 후보 광고를 함께 넣어 가중치 하나를 내는 작은 신경망이고, 행동마다 한 번씩 돕니다. 넷째 층은 행동 벡터에 그 가중치를 곱해 모두 더합니다. 이 결과를 관심 벡터라고 부릅니다. 이 두 층이 그림의 점선 칸이고, 앞 글의 target attention 이 바로 여기입니다.

다섯째 층에서 사용자 정보, 관심 벡터, 광고 벡터, 맥락을 한 줄로 이어 붙입니다. 여섯째 층 MLP 가 이것을 받아 사용자와 광고를 섞어 계산하고, 마지막 층이 클릭 확률 pCTR 을 냅니다. 논문 그림의 MLP 는 칸 200개, 80개짜리 층을 거쳐 두 칸 softmax 로 끝납니다.

그림 위 버튼으로 광고를 바꾸면 점선 칸 안의 가중치 넷과 관심 벡터만 바뀝니다. 나머지 층은 모양도 계산도 그대로입니다. 합이나 평균으로 묶던 이전 구조(Embedding 과 MLP)와 다른 곳이 이 점선 칸 하나뿐이라는 뜻입니다. 논문이 비교한 기준 모델은 행동 벡터를 모두 더했습니다. 그렇게 더하던 자리에 광고를 보고 가중치를 매기는 층을 넣은 것이 DIN 입니다.

## 2. 길이는 어디서 다른가: 임베딩이 아니라 행동의 개수

**행동 하나의 임베딩은 고정 길이입니다. 사람마다 다른 것은 행동의 개수입니다. DIN 이 푼 것은 길이 자체가 아니라, 그 행동들을 고정 길이 하나로 줄일 때 관심이 뭉개지는 문제입니다.**

| 무엇 | 길이 | 이 글에서 |
|---|---|---|
| 행동 하나의 임베딩 | 고정 | 누구든 숫자 4칸. 실제 모델은 32칸, 64칸 같은 값입니다 |
| 행동 기록 | 사람마다 다름 | 민지 씨는 4개, 다른 사람은 200개일 수 있습니다 |
| 관심 벡터 (가중합 결과) | 고정 | 몇 개를 더하든 4칸 하나입니다 |

MLP 는 고정 길이 입력만 받습니다. 그래서 가변 길이 기록을 고정 길이 하나로 줄이는 층이 반드시 필요합니다. DIN 이전 구조도 이 층이 있었고, 합이나 평균으로 줄였습니다. 길이 문제만 보면 이것으로 이미 풀립니다.

그런데 합이나 평균은 어느 광고 앞에서나 같은 벡터 하나를 냅니다. 러닝과 커피처럼 관심이 여럿인 사람을 벡터 하나에 다 담기 어렵습니다. DIN 논문 초록도 이 점을 짚습니다. Embedding 과 MLP 구조는 후보 광고와 상관없이 사용자 특성을 고정 길이 벡터 하나로 줄이고, 이 고정 길이 벡터가 병목이 된다고 적습니다.

DIN 은 줄이는 방법만 바꿨습니다. 광고를 보고 행동마다 가중치를 매겨 더합니다. 결과는 여전히 고정 길이 4칸이지만 광고마다 다른 벡터가 나옵니다. 그래서 길이를 늘리지 않고도 여러 관심을 나타냅니다.

학습할 때는 한 배치 안 기록의 길이가 서로 다릅니다. 보통 가장 긴 길이에 맞춰 빈칸(padding)을 채우고, 빈칸의 가중치를 0 으로 만드는 mask 를 같이 넘깁니다. 4절 코드의 마지막 부분이 그 계산입니다. 이것은 구현 방법이고 논문의 핵심은 아닙니다.

## 4. activation unit: 가중치 하나를 내는 작은 신경망

**행동 하나와 광고 하나를 이어 붙여 작은 신경망에 넣으면 가중치 하나가 나옵니다. 러닝 양말과 러닝화 광고라면 2.4 입니다.**

입력은 행동 4칸, 광고 4칸, 둘의 차이 4칸, 칸끼리의 곱 4칸을 이어 붙인 16칸입니다. 곱 칸은 두 벡터가 같은 쪽을 가리킬수록 커집니다. 러닝 양말 [0.7, 0.1, 0.6, 0.9] 와 러닝화 광고 [0.85, 0.15, 0.8, 0.9] 의 곱은 [0.595, 0.015, 0.48, 0.81] 이고 합이 1.9 입니다.

이 글의 신경망은 「곱 칸의 합이 0.3 을 넘는 만큼 1.5배」를 내도록 배웠다고 놓았습니다. (1.9 − 0.3) × 1.5 = 2.4 가 가중치입니다. 실제 신경망은 16칸 전부에 학습된 가중치가 붙고 숨은 칸이 수십 개입니다. 이 계산을 행동 넷에 한 번씩 하면 3절의 가중치 넷이 나옵니다.

논문 그림의 activation unit 은 행동, 광고, 둘의 외적(outer product)을 이어 붙여 칸 36개짜리 층과 활성 함수, 칸 1개짜리 층을 거칩니다. 활성 함수는 PReLU 나 논문이 새로 낸 Dice 를 씁니다. 외적 자리에 차이와 칸끼리의 곱을 넣는 것은 DeepCTR 같은 공개 구현의 방식이고, 이 글의 16칸이 그쪽을 따랐습니다.

가중치를 내는 신경망은 따로 정답을 받지 않습니다. 「이 행동이 이 광고와 얼마나 관련 있나」를 누가 적어 주지 않습니다. 클릭 여부 하나를 맞히도록 pCTR 신경망과 함께 학습되면서, 클릭을 잘 맞히는 가중치를 스스로 찾습니다.

```python
# DIN 의 activation unit 을 손으로 돌린다. 숫자는 행동 시퀀스 Attention 글과 같은 가상 값이다.
import math

E = {"러닝화 A": [0.9, 0.1, 0.8, 0.2], "러닝화 B": [0.8, 0.2, 0.8, 0.2],
     "커피 원두": [0.1, 0.9, -0.7, 0.5], "러닝 양말": [0.7, 0.1, 0.6, 0.9]}
ADS = {"러닝화 광고": [0.85, 0.15, 0.8, 0.9], "커피머신 광고": [0.15, 0.8, -0.7, 0.9]}


def activation_unit(e, v):
    """[행동, 광고, 차이, 곱] 16칸 → 가중치 하나. 곱 칸의 합이 0.3 을 넘는 만큼 1.5배라고 배웠다고 놓는다."""
    x = e + v + [a - b for a, b in zip(e, v)] + [a * b for a, b in zip(e, v)]
    h = max(0.0, sum(x[12:]) - 0.3)            # 앞 12칸에 붙은 가중치는 0 이라고 놓았다
    return 1.5 * h


def pool(history, ad):
    w = [activation_unit(e, ad) for e in history]
    user = [sum(wi * e[k] for wi, e in zip(w, history)) for k in range(4)]   # 길이는 늘 4칸
    return w, user


for name, v in ADS.items():
    w, user = pool(list(E.values()), v)
    soft = [math.exp(x) for x in w]
    print(f"{name}: 가중치 {[round(x, 3) for x in w]} 합 {sum(w):.2f}"
          f" / softmax {[round(x / sum(soft), 3) for x in soft]}")
    print(f"  관심 벡터 {[round(x, 3) for x in user]}")

# 기록 길이가 다른 두 사람을 한 배치에: 짧은 쪽은 빈칸을 채우고 mask 로 가중치를 0 으로
PAD = [0.0, 0.0, 0.0, 0.0]
short = [E["커피 원두"]]                                  # 행동 하나뿐인 사람
padded, mask = short + [PAD] * 3, [1, 0, 0, 0]
w = [activation_unit(e, ADS["커피머신 광고"]) * m for e, m in zip(padded, mask)]
user = [sum(wi * e[k] for wi, e in zip(w, padded)) for k in range(4)]
print(f"행동 1개 + 빈칸 3개: 가중치 {[round(x, 3) for x in w]} 관심 벡터 {[round(x, 3) for x in user]}")

# 출력:
# 러닝화 광고: 가중치 [1.95, 1.845, 0.0, 2.4] 합 6.20 / softmax [0.277, 0.249, 0.039, 0.434]
#   관심 벡터 [4.911, 0.804, 4.476, 2.919]
# 커피머신 광고: 가중치 [0.0, 0.0, 2.062, 0.413] 합 2.48 / softmax [0.088, 0.088, 0.691, 0.133]
#   관심 벡터 [0.495, 1.897, -1.196, 1.403]
# 행동 1개 + 빈칸 3개: 가중치 [2.062, 0.0, 0.0, 0.0] 관심 벡터 [0.206, 1.856, -1.444, 1.031]
```

마지막 줄은 행동이 하나뿐인 사람을 넷짜리 배치에 넣은 경우입니다. 빈칸 셋은 mask 로 가중치가 0 이 되어, 관심 벡터는 커피 원두 하나만으로 만들어집니다. 그래도 길이는 4칸이라 뒤의 MLP 는 다른 사람과 같은 모양의 입력을 받습니다.

이 글의 activation unit 은 곱 칸만 보므로 빈칸을 넣으면 원래 0 을 냅니다. 실제 신경망은 다릅니다. 빈칸과 짝지은 16칸에도 광고 칸과 차이 칸은 0 이 아니고, 학습된 상수(bias)도 더해져서 0 이 아닌 가중치가 나올 수 있습니다. 그래서 mask 로 빈칸의 가중치를 따로 0 으로 만듭니다.

## 5. 가중치의 합이 1 이 아닌 까닭

**DIN 은 가중치를 softmax 로 나누지 않습니다. 그래서 관련 행동이 많은 광고일수록 가중치의 합이 커지고, 관심이 얼마나 센지가 벡터에 남습니다.**

| 광고 | DIN 가중치 (러닝화 A, 러닝화 B, 커피 원두, 러닝 양말) | 합 | softmax 로 나눴다면 |
|---|---|---|---|
| 러닝화 광고 | 1.950, 1.845, 0, 2.400 | 6.20 | 0.277, 0.249, 0.039, 0.434 (합 1) |
| 커피머신 광고 | 0, 0, 2.062, 0.413 | 2.48 | 0.088, 0.088, 0.691, 0.133 (합 1) |

민지 씨는 러닝 행동이 셋이고 더 최근입니다. 그래서 러닝화 광고의 합 6.20 이 커피머신 광고의 합 2.48 보다 큽니다. 러닝화 광고용 관심 벡터가 더 커지고, 뒤의 MLP 는 이 크기로 「러닝 관심이 더 세다」를 읽습니다.

softmax 로 나누면 두 합이 모두 1 이 되어 이 차이가 사라집니다. 또 softmax 는 0 을 못 만들어서, 러닝화 광고 앞에서도 커피 원두가 3.9% 를 가져갑니다. Transformer 의 attention 은 softmax 로 나누므로, DIN 을 볼 때 둘을 섞지 않는 것이 처음 헷갈리는 자리입니다.

## 6. 광고마다 pCTR: 가중치 계산을 후보 수만큼

**광고마다 만든 관심 벡터를 광고 벡터, 그 밖의 정보와 이어 붙여 MLP 에 넣으면 그 광고의 pCTR 이 나옵니다.**

러닝화 광고를 채점할 때는 [4.911, 0.804, …] 가, 커피머신 광고를 채점할 때는 [0.495, 1.897, …] 가 들어갑니다. 같은 사람인데 MLP 에 들어가는 사용자 쪽 입력이 광고마다 다릅니다. 그래서 커피머신 광고도 커피 원두 구매를 제대로 반영한 pCTR 을 받습니다.

대신 값이 듭니다. 관심 벡터가 광고마다 다르니 하나를 미리 계산해 둘 수 없습니다. 후보가 800개면 요청 한 건에 activation unit 을 행동 수 × 800번 돌립니다. 행동이 수만 개로 길어지면 관련 있는 행동을 먼저 고른 뒤 같은 계산을 하고, 그 이야기는 행동 시퀀스 Attention 글의 뒷부분에 있습니다.

## 한눈 정리

| 층 | 하는 일 | 이 글의 숫자 |
|---|---|---|
| 입력 | 사용자 정보, 행동 기록, 후보 광고, 맥락 네 묶음 | 행동 넷, 광고 둘 |
| 임베딩 | 번호를 벡터로. 행동마다 고정 길이 | 4칸 |
| activation unit | 행동 하나와 광고를 함께 보고 가중치 하나 | 러닝 양말 × 러닝화 광고 2.4 |
| 가중합 | 가중치를 곱해 더해 광고용 관심 벡터 하나 | 러닝화 광고 [4.911, 0.804, 4.476, 2.919] |
| 이어 붙이기 | 네 덩어리를 한 줄로 | 사용자 정보, 관심, 광고, 맥락 |
| MLP | 사용자와 광고를 섞어 계산 | 논문 그림 200 → 80 |
| 출력 | 클릭 확률. 클릭 하나로 모든 층을 함께 학습 | 광고마다 다른 pCTR |

## 헷갈리기 쉬운 점

- **가변 길이는 임베딩이 아니라 행동의 개수입니다.** 행동 하나의 임베딩은 늘 같은 길이이고, 관심 벡터도 고정 길이입니다.
- **DIN 이전에도 길이 문제는 합이나 평균으로 풀렸습니다.** DIN 이 푼 것은 고정 길이 벡터 하나가 광고를 모른 채 만들어지는 병목입니다.
- **attention 은 일곱 층 가운데 둘뿐입니다.** 나머지 층은 합이나 평균으로 묶던 모델과 같습니다.
- **가중치의 합은 1 이 아닙니다.** softmax 로 나누지 않아 관심의 세기가 남습니다.
- **가중치에는 따로 정답이 없습니다.** 클릭 여부 하나로 모든 층이 함께 학습됩니다.
