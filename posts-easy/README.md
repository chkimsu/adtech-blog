# posts-easy

글의 쉬운 판을 모아 두는 폴더입니다. 원래 글과 나란히 비교하려고 따로 둡니다.

- 파일 이름은 `posts/<id>.md` 와 같은 `<id>.md` 입니다. 같은 id 를 `js/easy-posts.js` 의 `EASY_POST_IDS` 에 적어야 글 페이지에서 이 판이 열립니다.
- `post.html?id=<id>` 로 열면 쉬운 판이 먼저 나옵니다. 원래 판은 `post.html?id=<id>&v=original` 로 열고, 두 판의 맨 위에 서로 가는 링크가 있습니다. 예전 주소의 `&v=easy` 도 쉬운 판을 엽니다. 일반 글과 같은 렌더러를 씁니다.
- 처음부터 쉬운 판 말투로 쓴 글(알고리즘 새 글 5편, 과외 10편)은 이 폴더에 파일이 없습니다. `js/easy-posts.js` 의 `EASY_NATIVE_IDS` 에 적어 카드와 검색의 「쉬운 판」 표시, 탐색 페이지의 「쉬운 판 있는 글만」 에 함께 넣습니다.
- 코드 블록과 `# 출력:` 에 찍힌 값은 원래 글과 글자까지 같아야 합니다. 바꾸는 것은 설명 문장뿐입니다.
- 글 목록, 검색 색인, 사이트맵, 피드와 `posts/*.md` 를 도는 검사는 이 폴더를 보지 않습니다.
