보상 루프 카드 네 장

판정자의 점수를 보상으로 써서 카피를 쓰는 모델을 학습하는 자리를 한 장씩 봅니다. 선호 쌍으로 배우는 보상 모델, KL 세기와 보상 해킹, GRPO 의 묶음 이점, 학습 도중의 판정자 교체입니다. 카피 후보 12개와 선호 쌍 20개, 참조 로그 확률은 설명을 위해 만든 가상 값입니다.

파랑 = 선호 쌍과 참조 정책 벽돌색 = 학습하는 정책 먹색 = 보상 모델(판정자 A, B) 회색 = 게이트에 걸린 카피 점선 = KL 항과 고정할 판정자 버전

REWARD LOOP

선호 쌍 → 보상 모델 → 정책

쉽게 말하면 선호 쌍으로 카피에 점수를 매기는 모델을 먼저 배우고, 카피를 쓰는 모델은 그 점수를 올리도록 배웁니다.

보상 모델은 20쌍을 모두 맞혔고, 글자 10자에 2.79 를 더합니다. 판정자 쌍을 빼고 배우면 -0.32 입니다.

REWARD HACKING

KL 을 약하게 걸수록

쉽게 말하면 출발점에서 멀어질 때의 벌점을 약하게 걸수록, 모델은 점수만 높은 카피로 쏠립니다.

β 를 2 에서 0.25 로 내리자 보상은 11.63 에서 17.77 로 올랐습니다. 통과율은 0.732 에서 0.000 이 되었습니다.

GROUP ADVANTAGE

묶음 평균을 기준으로

쉽게 말하면 카피 여러 개를 뽑아 평균보다 점수가 높은 카피는 늘리고, 평균보다 낮은 카피는 줄입니다.

카피 8개의 보상 평균은 7.05 이고, c03 의 이점은 +1.75 입니다. 60걸음 뒤 통과율은 0.255 에서 0.031 로 떨어졌습니다.

JUDGE SWITCH

학습 도중 판정자를 바꾸면

쉽게 말하면 점수를 매기는 모델을 중간에 바꾸면, 카피 모델은 그대로여도 기록에 남는 점수가 바뀝니다.

60걸음째 정책은 그대로인데 적힌 보상이 14.95 에서 2.34 로 떨어졌습니다. 120걸음에 B 로 잰 값은 2.40 으로, 처음부터 B 를 쓴 3.19 보다 낮습니다.

현업에서는 이렇게 씁니다

  • 판정자를 보상으로 쓸 때는 세 가지를 봅니다. 한 학습 동안 판정자를 고정했나, 게이트 통과율을 보상과 따로 재나, 체크포인트를 판정자 하나로 다시 재나.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 글로 이어 읽으려면 RLHF, RLAIF, GRPO 와 보상 모델 편에 이 카드들이 절마다 들어 있습니다. 같은 선호 쌍으로 DPO 를 돌린 글은 SFT 와 DPO 편입니다.
