슬라이딩 윈도우: 빼고 더하기와 다 더하기의 연산 수

길이가 정해진 창을 한 칸씩 옮기며 창 안의 합을 구할 때, 나간 값을 빼고 들어온 값을 더하는 방식과 매번 처음부터 다시 더하는 방식의 연산 수를 한 단계씩 비교합니다. 세 번째 탭에서는 크기가 변하는 창으로 중복 없는 가장 긴 부분 문자열을 찾습니다.

한 줄 요약
창을 한 칸 옮길 때 바뀌는 값은 나간 값 하나와 들어온 값 하나뿐이라, 이전 합에서 나간 값을 빼고 들어온 값을 더하면 창이 얼마나 크든 연산이 2번입니다. nums = [2, 1, 5, 1, 3, 2], k = 3 에서 매번 다 더하면 연산 12번, 빼고 더하면 9번입니다. 데이터 10만 개에 창 5만이면 다 더하기는 2,500,050,000번, 빼고 더하기는 150,000번입니다.
보여 주는 장면길이 k 인 연속 구간의 합이 가장 큰 곳을 찾는 문제입니다. 창을 한 칸 옮기면 창 안에서 바뀌는 값은 나간 값 하나와 들어온 값 하나뿐이라서, 가운데 k - 2개를 다시 더할 필요가 없습니다. 다 더하기는 창마다 k 개를 더해 연산이 (n - k + 1) × k 번이고, 빼고 더하기는 첫 창에 k 번, 이후 옮길 때마다 2번이라 k + 2 × (n - k) 번입니다.
목적두 방식의 연산 수를 같은 입력으로 세어 보고, 창이 커질수록 차이가 얼마나 벌어지는지 봅니다. 입력은 다섯 가지입니다. nums = [2, 1, 5, 1, 3, 2], k = 3 은 빼고 더하기 9번, 다 더하기 12번입니다. nums = [1, 12, -5, -6, 50, 3], k = 4 는 LeetCode 643 의 예제 입력이고 평균을 구합니다. nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8], k = 6 은 12칸 배열이고 빼고 더하기 18번, 다 더하기 42번입니다. 나머지 둘은 세 번째 탭의 s = "abcabcbb" 와 s = "pwwkew" 입니다.
결과 읽는 법결과 칸은 최대 합이고, 아랫줄에 같은 입력의 두 방식 연산 수와 데이터 10만 개, 창 5만일 때의 연산 수가 나옵니다. 입력이 짧으면 두 수가 비슷하지만(12번과 9번) 입력이 길수록 차이가 커집니다(2,500,050,000번과 150,000번). 창 합과 연산 수 칸의 「창 합」은 지금까지 더한 값이고 「연산 수」는 처음부터의 누적입니다. 배열에서 파란 테두리 안이 창, 옅은 파란 바탕이 들어온 값, 붉은 바탕이 나간 값, 진한 파란 바탕이 끝에 보이는 최대 합 창입니다. 세 번째 탭은 결과 칸이 best, 상태 칸이 창 안의 글자 set 입니다. 창 크기가 변하는 문제(합이 S 이상인 가장 짧은 구간)는 슬라이딩 윈도우 단계별 시각화에서 따로 봅니다.
    따라 하는 순서
  1. 탭 나간 값 빼고 들어온 값 더하기에서 입력은 nums = [2, 1, 5, 1, 3, 2], k = 3 입니다. 「한 칸」은 덧셈 하나 또는 창 이동 하나를 보입니다. 처음 세 번 누르면 첫 창 [2, 1, 5] 를 만들며 창 합이 2, 3, 8 이 되고 연산 수는 3번입니다. 이번 단계 칸이 방금 한 계산을 문장으로 적습니다.
  2. 「다음 창」은 창 하나를 만들거나 옮기는 데 필요한 동작을 한 번에 넘깁니다. 한 번 더 누를 때마다 창이 [1, 5, 1], [5, 1, 3], [1, 3, 2] 로 옮겨 가고 창 합은 7, 9, 6 이 됩니다. 두 번째 옮김에서 7 - 1 + 3 = 9 로 최대 합이 바뀌고, 한 번 옮길 때마다 연산이 2번씩 늘어 마지막에 9번이 됩니다. 「끝까지」를 누르면 결과 칸에 최대 합 9 가 나오고 창 [5, 1, 3] 이 진한 파란 바탕입니다.
  3. 탭 매번 다 더하기에서 같은 입력의 「다음 창」을 누르면 창 하나가 한 번에 처음부터 다시 더해집니다. 창마다 연산이 3번이라 창 4개에서 12번이 됩니다. 입력 목록에서 nums = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8], k = 6 을 고르고 「끝까지」를 누르면 연산 42번, 최대 합 30 이 나오고, 같은 합 30 인 창이 하나 더 있어 먼저 나온 창을 보인다고 적힙니다. 같은 입력의 빼고 더하기는 18번입니다.
  4. 입력 nums = [1, 12, -5, -6, 50, 3], k = 4 에서 탭 나간 값 빼고 들어온 값 더하기의 「끝까지」를 누르면 창 합 2, 51, 42 중 가장 큰 51 이 최대 합이고, 결과 칸에 평균 51 / 4 = 12.75 가 같이 나옵니다. 나가는 값이 -5 처럼 음수일 때는 식에 괄호가 붙습니다.
  5. 탭 중복 없는 부분 문자열에서 입력은 s = "pwwkew" 입니다. 「다음 창」은 글자 하나를 처리합니다. 세 번째 글자 w 는 창에 이미 있어서 왼쪽의 p 와 w 를 차례로 뺀 뒤 넣습니다. 「끝까지」를 누르면 결과 칸에 best 3 이 나오고 "wke" 가 진한 파란 칸으로 보입니다. 끝의 창 "kew" 도 길이 3 이지만 더 길지 않아 best 를 바꾸지 않습니다. 탭이나 입력을 바꾸면 처음 상태로 돌아갑니다.
