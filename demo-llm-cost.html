LLM 비용 놀이터

LLM 요청 한 건의 값은 입력 토큰과 출력 토큰에 단가를 곱해 셉니다. 하루 값은 거기에 하루 요청 수를 곱한 값입니다. 시스템 메시지를 캐시에서 읽는 몫이 하루 값을 얼마나 깎는지 슬라이더로 봅니다.

큰 모델로 하루 100만 요청을 보내면 캐시 없이 7,800,000원입니다. 시스템 메시지 1,000 토큰을 모두 캐시에서 읽으면 4,200,000원입니다. 출력 3,000,000원은 캐시와 상관없이 남습니다.
이 데모가 보여주는 것요청 한 건은 시스템 메시지 1,000 토큰과 사용자 메시지 200 토큰을 읽고 150 토큰을 씁니다. 작은 모델은 하루 720,000원, 큰 모델은 7,800,000원입니다. 토큰 셋, 캐시 적중 비율, 하루 요청 수, 모델을 바꾸며 네 숫자가 어떻게 움직이는지 봅니다.
왜 알아야 하나단가표만으로는 하루 값이 나오지 않습니다. 요청 한 건의 토큰과 하루 요청 수를 곱해야 나오고, 캐시는 입력 쪽만 깎습니다. 출력이 큰 서비스는 캐시를 다 맞혀도 값이 크게 줄지 않습니다.
    이렇게 해봅니다 — 5분
  1. 기본값에서 큰 모델의 하루 4,200,000원을 봅니다. 캐시를 다 맞힌 값입니다.
  2. 캐시 적중 비율을 0% 까지 내립니다. 하루 값이 7,800,000원이 됩니다.
  3. 출력 토큰을 늘려 봅니다. 캐시를 다 맞혀도 하루 값이 크게 오릅니다.

식 — 요청 한 건의 값은 LLM 모델 고르기 편의 cost_won 과 같은 식으로 셉니다. $p_{in}$ 과 $p_{out}$ 은 100만 토큰당 단가이고, $N_{in}$ 은 시스템과 사용자 메시지를 더한 입력 토큰입니다.

$$\mathrm{cost} = \frac{(N_{in} - N_{cache})\,p_{in} + 0.1\,N_{cache}\,p_{in} + N_{out}\,p_{out}}{10^6}$$

$N_{cache}$ 는 시스템 메시지 토큰에 캐시 적중 비율을 곱한 값입니다. 캐시에서 읽은 토큰은 입력 단가의 0.1배로 셉니다. 사용자 메시지와 출력은 캐시와 상관없이 단가 그대로입니다. 하루 값은 한 건의 값에 하루 요청 수를 곱하고, 한 달 값은 하루 값에 30을 곱합니다.

단가는 설명을 위해 정한 가상 값이고, 실제 단가는 회사마다 가격 문서에 있습니다. 작은 모델은 100만 토큰당 입력 400원과 출력 1,600원, 큰 모델은 4,000원과 20,000원으로 둡니다. 실제 API 는 캐시에 처음 쓸 때의 값과 캐시가 남는 시간을 따로 정하는데, 이 놀이터는 그 둘을 세지 않습니다.

캐시 적중 비율과 하루 값

지금 토큰과 하루 요청 수에서 캐시 적중 비율만 바꾼 선입니다. 점선은 출력의 하루 값이고, 캐시를 다 맞혀도 그 아래로 내려가지 않습니다.

요청 한 건의 값은 어디서 나오나

한 건의 값을 넷으로 나눈 막대입니다. 캐시가 깎는 것은 시스템 메시지 몫뿐이고, 사용자 메시지와 출력은 그대로입니다.

이 데모에서 알게 된 3가지

  1. 하루 값은 토큰과 요청 수의 곱입니다 — 같은 요청을 10배 보내면 하루 값도 10배입니다. 단가표만 보면 이 값이 나오지 않습니다.
  2. 캐시는 입력 쪽만 깎습니다 — 캐시를 다 맞히면 7,800,000원이 4,200,000원이 되고, 원래의 54% 에서 멈춥니다.
  3. 출력은 토큰 수보다 값이 큽니다 — 출력 단가가 입력의 4~5배라, 캐시를 다 맞힌 큰 모델에서 출력이 하루 값의 71% 입니다.

현업에서는 이렇게 씁니다

서비스에 LLM 을 붙이기 전에 이 셈을 먼저 해 봅니다. 단가는 가격 문서에서, 토큰 수는 기록한 응답의 usage 에서 가져옵니다. 그 둘이 있으면 하루 요청 수만 바꿔 가며 값의 크기를 봅니다.

  • 바뀌지 않는 글을 앞에 둡니다: 캐시는 프롬프트의 앞부분이 같을 때만 맞습니다. 시스템 메시지와 예시를 앞에, 바뀌는 질문을 뒤에 둡니다.
  • 캐시 적중은 usage 로 확인합니다: 응답의 usage 에 캐시에서 읽은 토큰 수가 나옵니다. 적중 비율은 가정하지 않고 그 수로 셉니다.
  • 출력을 줄이는 것도 셈에 넣습니다: 풀이를 먼저 쓰게 하면 출력 토큰이 늘어납니다. 비용, 캐시, 비결정성 편에서 그 몫을 셉니다.
