어떤 이커머스 광고팀이 신발 배너 광고를 두 달 돌렸다. 캠페인이 끝나고 로그를 열어봤다. 광고를 본 사람들의 구매율이, 안 본 사람들보다 훨씬 높게 나왔다. 팀장이 회의에서 말했다. "배너 광고 효과 확실하네요. 예산 더 씁시다."

그 결론을 보고서에 적기 전에, 딱 하나만 확인해 보자. 광고를 본 사람과 안 본 사람은, 애초에 같은 부류였을까? 이 질문에 제대로 답하는 법이 인과추론(causal inference)이고, 이 글은 그 방법을 다루는 인과추론 트랙의 첫 글이다.

> 한 줄 요약: 상관은 '같이 움직인다'는 관찰이고, 인과는 '내가 바꾸면 저것도 바뀐다'는 주장이다. 광고를 본 사람이 더 샀다고 해서, 광고 *때문에* 산 것은 아닐 수 있다. 그 사람들이 원래 더 살 사람들이었을 수도 있다.

## 1. 착시 — 광고 본 사람이 유독 많이 샀다

**노출군과 비노출군을 층으로 나누지 않고 그냥 비교하면, 광고 효과는 실제보다 몇 배나 부풀어 보인다.**

앞의 광고팀 이야기로 돌아가 보자. 로그에는 광고를 본 사람(노출군)과 못 본 사람(비노출군)의 구매 여부가 찍혀 있다. 이 둘의 구매율을 그냥 빼면 얼핏 그럴듯한 '광고 효과'가 나온다. 문제는 광고가 아무에게나 똑같이 보이지 않는다는 점이다. 실제 타겟팅은 이미 살 것 같은 사람에게 광고를 더 많이 보여준다. 그래서 노출군에는 애초에 구매 확률이 높은 사람이 더 많이 섞여 들어간다.

이 쏠림을 숫자로 보려면, 유저를 원래 살 마음(구매 의향)이 높은 층과 낮은 층으로 나눠야 한다. 아래 표는 20만 명의 유저를 이 두 층으로 나눈 결과다. 타겟팅이 노출을 어떻게 몰아주는지, 그리고 그 결과 층을 무시한 비교(naive)가 얼마나 부풀려지는지를 함께 보여준다.

**표 ① — 층별로 나눠 보면 줄어드는 '광고 효과'**

| 층 (원래 구매 의향) | 인원 | 노출 | 비노출 | 노출군 구매율 | 비노출군 구매율 | 차이 |
|---|---|---|---|---|---|---|
| 의향 높음 | 39,708명 | 35,827명 (90.2%) | 3,881명 (9.8%) | 22.1% | 20.4% | +1.6%p |
| 의향 낮음 | 160,292명 | 16,149명 (10.1%) | 144,143명 (89.9%) | 5.9% | 4.0% | +2.0%p |
| **전체 (층 무시 = naive 비교)** | 200,000명 | 51,976명 (26.0%) | 148,024명 (74.0%) | **17.0%** | **4.4%** | **+12.7%p** |

표를 위에서부터 읽어 보자. 의향 높은 층은 노출 여부와 상관없이 원래 구매율이 높다(20.4%). 의향 낮은 층은 원래 구매율이 낮다(4.0%). 그런데 타겟팅 탓에 노출은 의향 높은 층에 90.2%, 의향 낮은 층엔 10.1%만 몰린다. 그 결과 '노출군'이라는 그룹 자체가 원래 잘 사는 사람들로 가득 찬다.

마지막 줄이 naive 비교다. 층을 나누지 않고 노출군과 비노출군을 그냥 비교하면 차이가 +12.7%p로 튀어 오른다. 그런데 층 안에서만 비교하면(첫째·둘째 줄) 차이는 +1.6%p, +2.0%p로 뚝 떨어진다. 광고 자체의 효과는 거의 그대로인데, '누구를 노출군으로 세었는지'만 바꿔도 착시가 6배 넘게 부풀었다. 이 착시가 이 글 전체를 관통하는 문제다.

## 2. 파이썬으로 확인하기 — naive는 몇 배나 부풀렸나

**같은 데이터를 코드로 다시 만들어 보면, naive 효과가 참값보다 몇 배 부풀었는지 정확한 배수로 나온다.**

표 ①은 손으로 끼워 맞춘 숫자가 아니라, 20만 명의 유저를 한 명씩 시뮬레이션해 나온 결과다. 각 유저는 먼저 의향 층(높음 20%, 낮음 80%)에 배정된다. 그 층의 타겟팅 확률에 따라 노출 여부가 정해진다. 마지막으로 그 층의 원래 구매율에, 노출됐을 때만 광고 효과(+2%p)를 더해 실제 구매 여부가 정해진다.

아래 코드는 이 과정을 그대로 구현하고, 세 가지 효과 추정치를 나란히 뽑는다. (a) naive는 층을 무시한 전체 비교, (b) 층별 보정은 각 층 안에서 비교한 뒤 인구 비중으로 가중평균한 값이다. (c)는 노출을 층과 무관하게 무작위로 다시 배정하는 RCT 시뮬레이션이 알려주는 참값이다.

```python
# 가짜 광고 캠페인 데이터를 만든다. 유저는 '원래 구매 의향' 높음/낮음 두 층으로 나뉘고,
# 타겟팅 탓에 광고 노출은 의향 높은 층에 쏠린다(교란) — 표준 라이브러리만 쓴다.
import random
random.seed(42)

N = 200_000                        # 전체 유저 수
HIGH_SHARE = 0.2                   # 의향 높은 층 비중 20%
BASE_HIGH, BASE_LOW = 0.20, 0.04   # 광고가 없었을 때 각 층의 '원래' 구매율
TRUE_LIFT = 0.02                   # 광고가 실제로 올리는 구매율(참값, 두 층 동일)

def make_users(p_expose_high, p_expose_low):
    """층별 노출 확률만 받아 유저 (의향, 노출여부, 구매여부) 리스트를 만든다."""
    rows = []
    for _ in range(N):
        high = random.random() < HIGH_SHARE
        exposed = random.random() < (p_expose_high if high else p_expose_low)
        p_buy = (BASE_HIGH if high else BASE_LOW) + (TRUE_LIFT if exposed else 0.0)
        rows.append((high, exposed, random.random() < p_buy))
    return rows

def rate(rows):
    return sum(r[2] for r in rows) / len(rows) if rows else 0.0

def gap(rows):
    """노출군 구매율 - 비노출군 구매율."""
    e = [r for r in rows if r[1]]
    c = [r for r in rows if not r[1]]
    return rate(e) - rate(c), len(e), len(c)

# 관측 데이터: 타겟팅 때문에 노출이 '의향 높음' 층에 쏠린 상태 그대로 (90% vs 10%)
obs = make_users(p_expose_high=0.9, p_expose_low=0.1)

naive_gap, n_exp, n_unexp = gap(obs)                     # (a) 층을 무시하고 그냥 비교

layers = {"의향 높음": [r for r in obs if r[0]], "의향 낮음": [r for r in obs if not r[0]]}
layer_gaps = {name: gap(rows) for name, rows in layers.items()}
weights = [len(rows) for rows in layers.values()]
stratified_gap = sum(g[0] * w for g, w in zip(layer_gaps.values(), weights)) / sum(weights)  # (b)

p_rct = n_exp / N                                          # 같은 노출 비율을 유지한 채 배정만 랜덤화
rct = make_users(p_expose_high=p_rct, p_expose_low=p_rct)   # 노출이 의향과 무관해진다
rct_gap, _, _ = gap(rct)                                    # (c) 무작위 배정 시뮬레이션 참값

for name, (g, ne, nc) in layer_gaps.items():
    print(f"[{name}] 노출 {ne:,}명 / 비노출 {nc:,}명 · 차이 {g*100:+.1f}%p")
print(f"[전체, naive] 노출 {n_exp:,}명 / 비노출 {n_unexp:,}명 · 차이 {naive_gap*100:+.1f}%p")
print()
print(f"(a) naive 효과          {naive_gap*100:+.2f}%p")
print(f"(b) 층별 보정 효과       {stratified_gap*100:+.2f}%p")
print(f"(c) RCT 시뮬레이션 참값  {rct_gap*100:+.2f}%p")
print(f"naive는 층별 보정 대비 {naive_gap/stratified_gap:.1f}배, RCT 참값 대비 {naive_gap/rct_gap:.1f}배 부풀렸다")

assert naive_gap > stratified_gap * 3          # 착시가 몇 배 이상임을 스스로 검증
assert abs(stratified_gap - TRUE_LIFT) < 0.01   # 층별 보정은 참값 근처로 돌아온다
assert abs(rct_gap - TRUE_LIFT) < 0.01          # RCT 시뮬레이션도 참값 근처로 돌아온다

# 출력:
# [의향 높음] 노출 35,827명 / 비노출 3,881명 · 차이 +1.6%p
# [의향 낮음] 노출 16,149명 / 비노출 144,143명 · 차이 +2.0%p
# [전체, naive] 노출 51,976명 / 비노출 148,024명 · 차이 +12.7%p
#
# (a) naive 효과          +12.65%p
# (b) 층별 보정 효과       +1.90%p
# (c) RCT 시뮬레이션 참값  +2.00%p
# naive는 층별 보정 대비 6.7배, RCT 참값 대비 6.3배 부풀렸다
```

층별 보정(+1.90%p)과 RCT 시뮬레이션(+2.00%p)이 서로 거의 일치한다는 점이 중요하다. 무작위 배정을 실제로 하지 않아도, 교란변수(의향 층)만 제대로 나눠 통제하면 진짜 실험과 거의 같은 답을 얻을 수 있다는 뜻이다.

반면 naive는 층별 보정 대비 6.7배, RCT 참값 대비 6.3배 부풀었다. 이 배수가 이 글의 핵심 숫자다. "광고 본 사람이 더 샀다"는 관찰과 "광고가 그만큼 더 팔았다"는 결론 사이에는, 이렇게 몇 배씩 벌어질 수 있는 간극이 있다.

## 3. 반사실 — '광고를 안 본 세계'는 영원히 보이지 않는다

**한 사람에게서 '광고를 봤을 때'와 '안 봤을 때'를 동시에 관측할 수는 없다. 인과추론의 모든 어려움이 여기서 나온다.**

약으로 예를 들어 보자. 철수가 약을 먹고 3일 만에 나았다. 그런데 철수가 약을 안 먹었으면 며칠 걸렸을지는 알 수 없다. 철수는 이미 약을 먹어 버렸고, 그 선택은 되돌릴 수 없다.

광고도 똑같다. 유저 A가 광고를 보고 신발을 샀다고 하자. A가 광고를 안 봤어도 샀을지는 우리가 절대로 알 수 없다. A는 이미 광고를 본 세계에 속해 버렸다. 표로 정리하면 이렇다.

| 유저 | 광고를 본 세계의 결과 | 광고를 안 본 세계의 결과 | 실제로 관측되는 값 |
|---|---|---|---|
| 유저 A (노출됨) | 구매함 | ? — 영원히 모름 | 구매함 |
| 유저 B (미노출) | ? — 영원히 모름 | 구매 안 함 | 구매 안 함 |

두 사람 모두 결과가 하나씩 비어 있다. 이 빈칸은 시간이 지나도, 데이터를 아무리 더 모아도 채워지지 않는다. 같은 사람이 같은 순간에 광고를 보면서 동시에 안 볼 수는 없기 때문이다. 학계에서는 일어나지 않은 이 세계를 반사실(counterfactual)이라 부른다. 이 빈칸 문제는 인과추론의 근본 문제(fundamental problem)라 부른다.

그래서 인과추론은 결국 "이 사람 대신 빈칸을 채워줄 비슷한 남을 어떻게 찾을까"의 문제로 바뀐다. 그 비슷한 남을 잘못 고르면 무슨 일이 생기는지가 다음 절의 주제, 교란변수다.

:::deep 더 깊이 — 잠재적 결과 표기법: ATE와 ATT는 뭐가 다른가
반사실을 수식으로 다루려면 표기법이 필요하다. 유닛(사람) $i$에게 잠재적 결과(potential outcome) 두 개를 정의한다.

| 표기 | 뜻 |
|---|---|
| $Y_i(1)$ | $i$가 광고에 노출됐을 때의 결과 (예: 구매 여부) |
| $Y_i(0)$ | $i$가 광고에 노출되지 않았을 때의 결과 |

$i$ 개인의 인과효과는 $Y_i(1) - Y_i(0)$ 이지만, 앞 절 표에서 봤듯 둘 중 하나는 항상 관측되지 않는다. 그래서 개인 효과 대신 집단 평균을 본다. 이때 평균을 어느 집단에 대해 내느냐에 따라 이름이 갈린다.

$$\text{ATE} = E[\,Y_i(1) - Y_i(0)\,]$$

ATE(평균처치효과)는 전체 인구를 대상으로 한 평균이다. "모두에게 광고를 보여줬다면"과 "아무에게도 안 보여줬다면"의 차이를 뜻한다.

$$\text{ATT} = E[\,Y_i(1) - Y_i(0) \mid D_i = 1\,]$$

ATT는 노출된 사람만 놓고 잰 평균처치효과다. $D_i=1$은 실제 노출을 뜻하는 표시다.

이 글의 시뮬레이션에서는 두 층의 참 효과(TRUE_LIFT)를 똑같이 2%p로 맞췄다. 그래서 ATE와 ATT가 우연히 같은 값으로 떨어졌다. 실제 데이터는 이렇게 친절하지 않다. 이미 살 마음을 굳힌 의향 높은 층에는 광고가 거의 안 먹힌다고 해보자(+0.5%p). 반대로 관심 없던 의향 낮은 층에는 광고가 크게 먹힌다면 어떨까(+4%p). 타겟팅은 의향 높은 층에 노출을 몰아주므로, 노출군에서 관측되는 값은 ATE보다 ATT에 훨씬 가까워진다. "이 캠페인 효과가 얼마다"라는 문장은, 그래서 항상 "누구를 기준으로 잰 평균이냐"를 같이 밝혀야 한다.
:::

## 4. 교란변수 — 아이스크림과 익사, 그리고 광고판의 숨은 변수들

**아이스크림-익사 이야기의 정체는 '숨은 제3의 원인'이다. 광고판에는 이런 숨은 원인이 훨씬 다양한 얼굴로 숨어 있다.**

여름이면 아이스크림이 잘 팔린다. 같은 여름, 물놀이 익사 사고도 늘어난다. 그렇다고 아이스크림을 금지하면 익사가 줄어들까. 당연히 아니다. 진짜 원인은 더위다. 더위가 아이스크림 판매도, 물놀이도 동시에 늘렸을 뿐이다. 이렇게 결과 두 개를 동시에 일으키는 숨은 원인을 교란변수(confounder)라 부른다.

```mermaid
graph LR
  H["더위<br/>(숨은 원인)"] --> I["아이스크림 판매"]
  H --> D["익사 사고"]
  I -.->|"상관 — 원인 아님"| D
```

화살표는 원인이 흐르는 방향이다. 더위 → 아이스크림, 더위 → 익사는 실선(원인)이고, 아이스크림과 익사 사이의 점선은 상관일 뿐 원인이 아니다. 상관만 보고 화살표를 거꾸로 그리면(아이스크림이 익사의 원인이라고), 엉뚱한 정책이 나온다.

이 글 표 ①의 '구매 의향'도 똑같은 구조다. 의향이 노출 여부를 정하고(타겟팅), 동시에 구매 여부도 정한다(원래 살 사람이니까). 의향이라는 교란변수가 노출과 구매를 동시에 끌어올려서, 둘 사이에 없던 인과가 있는 것처럼 보이게 만들었다.

광고판에는 의향 말고도 교란변수 후보가 많다. 세 가지만 짚어 보자.

- **계절성** — 겨울에 코트 광고를 집중적으로 내보낸다. 겨울이라 코트 수요가 원래 늘어나는데, 그 증가분을 광고 효과로 착각하기 쉽다.
- **프로모션·할인 이벤트** — 세일 기간엔 광고 예산도 늘고 노출도 는다. 동시에 가격이 싸져 구매도 는다. 할인이 만든 구매를 광고가 만든 것으로 착각한다.
- **브랜드 검색량 급증** — 제품이 화제가 되면 회사가 광고 예산을 늘리고, 동시에 사람들이 관심이 생겨 검색·구매도 는다. 화제성이 만든 구매를 광고가 만든 것으로 착각한다.

교란변수의 진짜 문제는, 후보를 전부 찾아 통제하는 게 사실상 불가능하다는 점이다. 로그에 안 찍히는 성향(예: '원래 부지런히 검색하는 사람')도 얼마든지 숨어 있을 수 있다. 그래서 나온 해법이 다음 절의 두 갈래 길이다. 교란을 원천봉쇄하거나(무작위 배정), 통제 못 한 교란이 있어도 답을 얻을 수 있는 상황을 찾거나(준실험).

## 5. 두 갈래 길 — 랜덤 실험과 준실험

**반사실의 빈칸을 채우는 법은 크게 두 갈래다. 무작위로 직접 만들거나(RCT), 이미 벌어진 데이터에서 실험과 비슷한 상황을 찾거나(준실험).**

첫째 길은 동전 던지기다. 누구에게 광고를 보여줄지 무작위로 정하면, 의향 높은 사람도 낮은 사람도 노출군과 비노출군에 골고루 섞인다. 그러면 두 그룹 사이에 남는 차이는 오직 노출 여부뿐이니, 그 차이가 곧 순수한 광고 효과다. 앞서 2절 코드의 (c)가 바로 이걸 흉내 낸 것이고, 결과는 참값 2%p에 정확히 들어맞았다(2.00%p). 이게 인과추론의 황금기준, 랜덤 실험(RCT)이다. 다음 글에서 랜덤 실험을 더 깊이 다룬다: [랜덤 실험 자세히](post.html?id=rct-randomized-experiment).

둘째 길은 훨씬 흔하다. 광고는 보통 이미 전체 유저에게 뿌려진 뒤고, 절반을 일부러 꺼서 실험할 기회는 지나가 버린 경우가 많다. 비용·시간·정책 제약도 있다. 이럴 때는 이미 쌓인 데이터에서 "거의 무작위로 갈린 것처럼 보이는 상황"을 찾는다. 이걸 준실험(quasi-experiment)이라 부른다. 이 트랙의 나머지 글들이 다루는 도구는 세 가지다.

- **이중차분(DiD)** — 처치를 안 받은 옆 그룹의 시간 변화를 빌려 반사실을 그린다. [이중차분 자세히](post.html?id=difference-in-differences)
- **회귀불연속(RDD)** — 어떤 컷오프 바로 위/아래를 비교해 국소적인 효과를 읽는다. [회귀불연속 자세히](post.html?id=regression-discontinuity)
- **도구변수(IV)** — 처치를 우연히 흔드는 외부 요인을 지렛대 삼는다. [도구변수 자세히](post.html?id=instrumental-variables)

둘 중 어느 길을 고를지는 상황이 정한다. 표로 정리하면 이렇다.

| 판단 기준 | 랜덤 실험(RCT) | 준실험(DiD·RDD·IV) |
|---|---|---|
| 노출을 내가 직접 정할 수 있나 | 가능 | 불가능 (이미 벌어진 데이터) |
| 되돌리기 | 아직 늦지 않음 | 이미 전체 배포, 되돌릴 수 없음 |
| 필요한 준비 기간 | 실험 설계·집행 기간 필요 | 과거 데이터로 바로 분석 |
| 얻는 값의 신뢰도 | 참값에 가장 가까움 | 가정이 맞을 때만 참값에 근접 |
| 특히 잘 맞는 무대 | 닫힌 생태계 (6절) | 열린 RTB (7절) |

이 갈림길이 실제로 두 무대에서 어떻게 다르게 나타나는지, 다음 두 절에서 본다.

## 6. 담장 안에서는 실험이 1급 시민이다 [무대: 닫힌 생태계]

**네이버·카카오 같은 닫힌 생태계는 노출을 자기 손으로 직접 정할 수 있어, RCT 홀드아웃을 깔끔하게 짤 수 있다.**

플랫폼은 로그인 기반으로 자기 유저 전체를 갖고 있다. 그래서 유저 100만 명 중 절반에게는 광고를 보여주고, 나머지 절반에게는 일부러 안 보여주는 홀드아웃을 손쉽게 나눌 수 있다. 5절에서 본 '동전 던지기'를 실무에서 그대로 실행하는 셈이다.

이 홀드아웃을 실제 숫자로 어떻게 돌리는지는 이미 다른 글에서 다뤘다. 노출군과 대조군의 구매율을 비교해 증분(incrementality)과 겉보기 CPA를 가르는 계산이다. [어트리뷰션 입문 7절](post.html?id=attribution-basics)에 그 계산이 있다. 거기서 본 '노출군 2.50% 대 대조군 2.00%' 비교가, 이 글 5절의 RCT를 실제 캠페인 숫자로 옮긴 사례다.

물론 홀드아웃이 쉽다고 모든 게 저절로 해결되진 않는다. 표본이 작으면 우연한 차이를 진짜 효과로 오해할 수 있다. 실험 기간이 짧으면 장기 효과를 놓치기도 한다. 그래도 '노출을 내 마음대로 못 정한다'는 열린 RTB 쪽의 근본적인 제약이 없다는 점 자체가 크다.

---

## 7. 열린 RTB에서는 준실험에 기댄다 [무대: 열린 RTB]

**노출을 매체가 쥐고 있고 사람 단위 추적도 어려운 열린 RTB에서는, 깨끗한 홀드아웃 대신 준실험과 집계 기반 기법에 기댄다.**

광고주가 캠페인을 집행해도, 실제로 누구에게 몇 번 보여줄지는 대개 매체나 거래소의 알고리즘이 정한다. 광고주 마음대로 절반을 완전히 꺼 버리는 실험은 매체의 협조 없이는 어렵다. 노출을 직접 통제하지 못하니, 5절의 첫째 길(RCT)을 쓰기가 훨씬 까다롭다.

게다가 사람 단위로 노출과 구매를 잇는 일 자체가 점점 어려워지고 있다. 서드파티 쿠키 축소와 iOS ATT 이야기는 이미 다뤘다. 자세한 내용은 [어트리뷰션 입문 6절](post.html?id=attribution-basics)에 있다. 개인 단위 반사실 비교가 힘드니, 측정은 자연히 지역·시간 단위로 뭉쳐 비교하는 쪽으로 옮겨간다.

그래서 이 세계에서는 준실험 쪽에 무게가 실린다. 옆 지역·옆 기간을 대역 배우로 세우는 이중차분(DiD)이 대표적이다. 입찰가나 빈도 캡 같은 자연적 컷오프를 쓰는 회귀불연속(RDD)도 쓰인다. 매체 쪽 우연한 변동을 지렛대로 삼는 도구변수(IV)도 마찬가지다. 광고주 입장에서 "우리 캠페인이 진짜 효과가 있었나"를 물어야 한다면, 담장 밖에서는 이 준실험 도구부터 배워야 하는 이유이기도 하다.

## 8. 한눈 정리

| 개념 | 뜻 | 이 글에서 본 숫자 | 핵심 |
|---|---|---|---|
| 상관 vs 인과 | 같이 움직임 vs 내가 바꾸면 바뀜 | naive 노출군 17.0% vs 비노출군 4.4% | 상관이 커도 인과라는 보장은 없다 |
| 교란변수(선택 편향) | 노출과 결과를 동시에 흔드는 숨은 원인 | 의향 높은 층에 노출 90.2% 쏠림 | 비교 대상이 애초에 다르면 효과가 부풀려진다 |
| naive vs 층별 보정 vs RCT | 세 가지 추정 방식 | +12.7%p vs +1.9%p vs +2.0%p | naive가 6~7배 과대 |
| 반사실(counterfactual) | 안 일어난 세계의 결과 | 유저 A·B 표의 '?' | 한 사람에게선 절대 동시에 못 본다 |
| ATE vs ATT | 전체 평균 vs 노출된 사람만의 평균 | 이 글에서는 우연히 둘 다 2%p | 실무에선 서로 다를 수 있어 구분이 필요 |
| RCT vs 준실험 | 직접 무작위 배정 vs 데이터에서 찾기 | RCT 시뮬레이션 +2.00%p | 못 하면 DiD·RDD·IV로 흉내 낸다 |

## 9. 헷갈리기 쉬운 점

- **상관이 강하다고 인과인 건 아니다.** naive 비교는 +12.7%p라는 큰 차이를 보였지만, 실제 효과는 +2%p 근처였다. 상관의 크기와 인과의 크기는 다른 숫자다.
- **"A/B 테스트만 하면 다 해결된다"는 절반만 맞다.** 무작위 배정은 교란을 없애 주지만, 표본이 작거나 기간이 짧으면 우연과 진짜 효과를 못 가른다.
- **눈에 보이는 것만 교란변수가 아니다.** 구매 의향처럼 로그에 안 찍히는 성향도 노출과 결과를 동시에 흔든다. 통제 못 한 교란은 상관표에 흔적을 남기지 않는다.
- **ATE와 ATT를 같은 숫자로 착각하기 쉽다.** 이 글의 예시는 둘을 일부러 같게 맞췄을 뿐, 실무 데이터에서는 종종 달라진다.
- **반사실은 '아직 모른다'가 아니라 '영원히 알 수 없다'는 뜻이다.** 데이터를 더 모은다고 채워지는 빈칸이 아니다. 그래서 비슷한 남을 빌려오는 전략(RCT·준실험) 자체가 필요해진다.
- **층별로 나누기만 하면 항상 답이 나온다는 것도 착각이다.** 표 ①은 의향이라는 교란변수를 이미 알고 있었기에 나눌 수 있었다. 못 찾은 교란변수는 층을 나눠도 그대로 숨어 있다.
