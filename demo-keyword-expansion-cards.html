키워드 확장 전략 카드 네 장

서연 씨 러닝화의 상품 설명 하나와 키워드 120개로, 모델이 전략 일곱의 키워드를 고르는 자리를 한 장씩 봅니다. 전략 일곱과 사전 속 정답, 한 번에 부르기와 전략마다 부르기, 전략 사이의 겹침, 코드가 하는 거르기입니다. 키워드, 정답, 하루 검색 수는 설명용 가상 값이고, 모델의 답은 qwen3.5:27b 의 기록입니다.

파랑 = 사전과 정답, 코드가 남긴 키워드 벽돌색 = 모델이 고른 키워드와 그 답 회색 = 정책 거르기로 빠지는 health 키워드 점선 상자 = 시스템 메시지에 적어 둔 정의

STRATEGIES

상품 설명 하나를 일곱 가지 질문으로 읽는다

쉽게 말하면 같은 러닝화라도 이름을 묻는지, 같이 사는 물건을 묻는지에 따라 답이 되는 검색어가 다릅니다. 정답은 사전의 키워드마다 붙여 둔 가상 값입니다.

정답이 있는 키워드는 44개입니다. problem_goal 의 정답 10개에는 무릎통증 같은 health 키워드 4개가 들어 있습니다.

ONE VS EACH

같은 정의로 한 번에 묻기와 전략마다 묻기

쉽게 말하면 한 번에 물으면 호출은 하나지만 답 하나에 일곱 전략을 다 적습니다. 따로 물으면 호출이 일곱으로 늘고, 각 전략은 다른 전략의 답을 모른 채 고릅니다.

맞은 수의 합은 전략마다 부른 30/44 가 가장 많았습니다. 한 번에 부를 때 thinking 을 켜면 17개만 골랐고, 일곱 번 부를 때 켜면 1,980.5초가 걸렸습니다.

OVERLAP

두 전략 이상이 고른 id 를 묶음마다

쉽게 말하면 따로 부른 전략은 서로의 답을 보지 못합니다. 그래서 러닝화처럼 두 전략에서 다 고른 이름이 양쪽 목록에 들어갑니다.

전략마다 따로 부른 답은 id 14개가 두 전략 이상에 들었습니다. 한 번에 부른 답은 2개와 0개였습니다.

FILTER

겹침을 하나로 남기고 health 와 noise 를 뺀다

쉽게 말하면 코드는 전략 차례로 합치며 앞 전략에 이미 있는 id 를 빼고, 주제가 health 나 noise 인 id 를 뺍니다. 같은 답에는 늘 같은 목록이 나옵니다.

최종 목록은 34, 15, 30, 26개입니다. 한 번에 thinking 을 끈 답이 러닝 키워드 40개 가운데 가장 많은 34개를 남겼습니다.

현업에서는 이렇게 씁니다

  • LLM 이 고른 키워드 목록을 받으면 세 가지를 묻습니다. 사전 밖 id 가 있었나, 전략 사이에 무엇이 겹쳤나, 정책 거르기로 무엇이 빠졌나.
  • 카드를 누르면 위 해설 칸에 그 자리에서 헷갈리는 것 하나가 더 나옵니다.
  • 글로 이어 읽으려면 키워드 확장 전략 편에 이 카드들이 절마다 들어 있습니다. 키워드 120개와 정답 전략은 유저를 문서로 편에서 처음 나왔습니다.
