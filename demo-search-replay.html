질의 하나 따라가기 기록

노트북 한 대에 Elasticsearch 노드 둘과 검색 API 를 띄우고, 광고 상품 3만 건을 색인해 질의를 보냈습니다. 상품 이름은 브랜드, 속성, 품목을 이어 만든 가짜입니다. 이 페이지는 그때 받은 응답을 다시 그립니다. 숫자는 지어낸 값이 아니라 그때 받은 값이고, 노트북에서 측정한 값이므로 ms 의 크기보다 어느 자리가 큰지를 봅니다.

파랑 = BM25, 글자로 찾은 목록 벽돌색 = kNN, 뜻으로 찾은 목록 먹색 = 두 목록을 RRF 로 합친 목록 회색 = 거른 것, 레플리카

1질의 하나가 BM25 100개와 kNN 100개를 거쳐 후보가 되는 길

질의 셋을 보냈습니다. 글자가 같은 「캠핑 의자」, 상품 이름에 없는 말 「헤드셋」, 동의어 사전이 운동화로 이어 주는 「스니커즈」입니다. 질의마다 BM25 와 kNN 으로 100개씩 찾고, RRF 로 합친 뒤 꺼진 상품을 뺐습니다.

100배 느리게 그립니다 +0.0ms
API 안의 CPU 일 (질의 벡터, RRF, 거르기)BM25 질의 왕복kNN 질의 왕복

BM25 위 10개점수 = BM25

    kNN 위 10개점수 = (1 + 코사인) ÷ 2

      RRF 로 합친 위 10개점수 = Σ 1 ÷ (60 + 순위)

        위 칸 다섯이 차례로 찹니다. BM25 와 kNN 은 각각 Elasticsearch 에 한 번씩 묻는 왕복이고, 질의 벡터와 RRF 와 거르기는 API 안의 계산입니다. 이 실습 환경은 둘을 차례로 불러 두 왕복이 더해집니다. 셋째 목록의 B 와 K 는 그 상품이 BM25 와 kNN 목록에서 몇 위였나입니다. 한쪽에만 있는 상품은 다른 쪽 표시가 없습니다.

        2인덱스 하나는 샤드 둘이고, 샤드마다 복사본이 두 노드에 하나씩 있습니다

        읽기 별칭이 가리키는 인덱스의 샤드 지도입니다. 질의 하나는 샤드 0 과 샤드 1 에 한 번씩 가고, 두 샤드의 답을 합쳐 위 10개를 고릅니다.

        실선이 primary, 점선이 replica 입니다. 둘은 같은 문서를 갖고, 읽기는 어느 쪽이 받아도 됩니다. 노드 하나가 꺼져도 남은 노드에 샤드 0 과 1 이 다 있어 검색이 계속됩니다. 쓰기는 primary 가 먼저 받고 replica 로 복사합니다.

        3운영 인덱스에 바로 넣을 때와 새 인덱스로 바꿀 때의 p99

        초당 50건의 검색을 보내는 채로 상품 피처를 두 방법으로 바꿨습니다. (가)는 지금 읽는 인덱스에 1만 5천 건을 바로 bulk 했고, (나)는 3만 건 전부로 새 인덱스를 만들어 별칭을 옮겼습니다.

        0초 / 82초
        p99, 1초 동안 가장 느린 1% 의 경계p50, 가운데 값(가) 바로 bulk(나) 새 인덱스 만들기와 교체

        (가)는 읽고 있는 인덱스의 문서 절반을 지우고 다시 넣는 일입니다. 그 8.8초 동안 색인 일과 검색이 같은 노드의 CPU 와 디스크를 나눠 썼습니다. (나)도 p99 가 올랐습니다. 이 실습 환경은 노드 둘이 새 인덱스 만들기와 검색을 같이 하기 때문입니다. 그래도 평균은 절반쯤이었고 교체 자체는 22ms 에 끝났습니다. 그래프의 표시선은 1초마다 색인기 상태를 읽어 찍어서 단계 경계가 1초쯤 어긋날 수 있습니다. 걸린 시간 칸은 색인기가 직접 측정한 값입니다.

        현업에서는 이렇게 씁니다

        • 검색 결과가 비었다는 문의는 분석기부터 봅니다. 질의가 어떤 토큰으로 쪼개졌고, 색인된 상품 이름은 어떤 토큰인지 _analyze 로 나란히 놓습니다. 「헤드셋」처럼 사전에 없는 말은 BM25 가 0건입니다.
        • kNN 은 꺼지지 않는 대신 틀릴 수 있습니다. 늘 100개를 돌려주므로 0건은 없지만, 작은 임베딩 모델은 「스니커즈」에 선글라스를 1위로 줬습니다. 그래서 BM25 와 같이 씁니다.
        • RRF 는 점수가 아니라 순위만 봅니다. BM25 점수와 코사인 점수는 단위가 달라 바로 더할 수 없습니다. 순위로 바꾸면 더할 수 있습니다.
        • 날마다 바뀌는 피처는 새 인덱스로 만들어 별칭을 옮깁니다. 옛 인덱스를 지우지 않고 두면 별칭만 되돌려 롤백합니다.
        • 글로 이어 읽으려면 Elasticsearch 하이브리드 검색에 이 그림 셋이 절마다 들어 있습니다.
