API 한 건을 직접 만들어 보기

보내고, 받고, 로그가 남기까지. 값을 바꿔 가며 눌러 보면 무엇이 달라지는지 그 자리에서 보입니다.

골라 읽는 법 — 절이 6개인 긴 페이지입니다. 처음부터 다 볼 필요 없습니다.
  • API 한 건이 어떻게 생겼는지만 → 1~2절
  • 로그를 누가 남기는지만 → 3절
  • 앱이 부를 때와 서버가 부를 때의 차이만 → 4절
  • 주소 이름 짓는 법만 → 5절

1. 요청 한 건은 이렇게 생겼습니다

2. 받는 쪽은 무엇을 보고 무엇을 돌려줍니까

3. 이 줄은 누가 남깁니까

4. 부르는 쪽이 앱이냐 다른 서버냐

5. 그래서 주소 이름을 나눕니까

6. 이 한 건이 남긴 줄
