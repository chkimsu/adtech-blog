지훈이 밀려난 소재 넷을 다시 띄우려고 하루 노출에서 1,000건을 떼어 놓았다. 클릭 한 건이 ₩500 인 지면이라, 그 몫은 매출을 담보로 내는 실험비다. 문제는 그 1,000건을 누구에게 어떻게 나눠 줄지다.

여덟에 고루 뿌리면 진짜 나쁜 소재에도 같은 몫이 간다. 밀려난 넷에게만 몰아 주면 한 소재가 받는 표본은 커지지만 나쁜 소재에 더 크게 걸린다. 노출은 그대로 두고 학습 가중치만 고치는 방법도 있는데, 그건 화면에 뜨는 것을 아무것도 바꾸지 않는다.

**그래서 어느 쪽이 얼마를 되찾아 주나?** 세 방법 다 밀려난 소재를 실제로 되살리기는 한다. 다른 것은 되살리는 속도와, 그동안 포기하는 클릭이다.

이 글은 처방 넷을 같은 판에 걸어 그 대가를 잰다. 앞 글에서 사흘 만에 굳어 버린 그 판이다. 결론부터 말하면, 탐색에 쓴 돈은 이미 옳게 굳은 판에서는 그냥 손해이고 잘못 굳은 판에서만 값을 한다.

> **한 줄 요약:** 굳음을 푸는 처방은 전부 노출을 떼어 주는 일이고, 떼어 준 노출은 그날의 매출이다. 그 지출이 값을 하는 판과 그냥 손해인 판이 갈리는데, 미리 어느 쪽인지 알 방법이 없어서 예산으로 잡는다.

**앞 글을 먼저 보면 좋다** — [어제 띄운 광고만 학습 데이터가 된다](post.html?id=feedback-loop-bias)가 이 판을 만든다. 광고 여덟을 진짜 클릭률이 높은 순서로 A 부터 H 까지 부르고, 로그와 코드에는 광고 번호로 찍힌다. A 가 `9931`, H 가 `9938` 이다.

**무대 표시 읽는 법** — `열린 RTB` 는 남의 거래소에 입찰만 넣는 자리이고, `닫힌 생태계` 는 우리가 경매를 직접 돌리는 자리다. `공통` 은 두 자리 모두에 해당한다는 뜻이다.

앞 글과 같은 판을 쓴다. 하루 노출 20,000건, 광고당 하루 상한 6,000건, 첫날 광고당 500건, 세대는 40이다. 기본으로 돌리면 사흘째에 노출 자리의 주인이 정해지고 A 는 40일 내내 화면에 못 뜬다.

## 1. 처방 넷은 무엇을 다르게 하나 [무대: 공통]

**굳음을 막는 방법은 결국 하나다. 추정값이 낮은 광고에도 노출을 떼어 주는 것이다. 갈리는 것은 누구에게 얼마를 떼어 주느냐다.**

먼저 이름 넷을 풀어 둔다. 앞의 셋은 화면에 뜨는 광고를 바꾸는 처방이고, 마지막 하나만 성격이 다르다.

- **ε 탐색** — 하루 노출에서 일정 비율을 떼어 여덟에게 똑같이 나눠 준다. ε 이 그 비율이다.
- **낙관적 초기값** — 아직 안 본 광고의 시작 추정값을 실제보다 높게 잡는다. 그러면 안 본 광고가 순위 위로 올라온다.
- **강제 슬롯** — 그날 노출이 0건이 된 광고에게만 몫을 떼어 준다.
- **역확률 가중** — 배분은 그대로 두고 학습 가중치만 고친다. 옛 배분이 그 광고를 고를 확률의 역수로 가중하는 방법이다.

같은 판에 넷을 걸어 보자. 아래 표는 각 처방이 하루 20,000건 중 얼마를 탐색에 쓰고, 그 몫이 한 광고에게 얼마씩 돌아가는지를 정리한 것이다.

| 처방 | 규칙 | 탐색에 쓰는 노출 | 한 광고가 받는 몫 |
|---|---|---|---|
| ε 탐색 5% | 20,000건 중 1,000건을 여덟에 균등 분배 | 1,000건 | 125건 (모든 광고) |
| 낙관 초기값 | 안 본 광고를 3.5% 라고 가정하고 시작 | 정해진 값 없음 | 그때그때 다름 |
| 역확률 가중 | 학습 표본에 1 ÷ 노출확률 가중 | 0건 | 0건 |
| 강제 슬롯 8% | 20,000건 중 1,600건을 0건 광고에게만 | 1,600건 | 400건 (밀려난 넷) |

**역확률 가중만 노출을 하나도 쓰지 않는다.** 그래서 매출을 한 푼도 포기하지 않는데, 대신 굳음을 풀지도 못한다. 앞 글 4절이 그 이유를 잰다 — 노출이 0건인 광고는 성향점수가 0이라 나눗셈에서 아예 빠진다.

나머지 셋은 전부 그날의 매출을 조금 포기하고 정보를 산다. ε 탐색 5% 면 하루 1,000건, 클릭 한 건에 ₩500 인 지면에서는 그 자리에 원래 실릴 매출을 매일 내놓는 셈이다. 그 지출이 얼마를 되찾아 주는지가 이 글의 질문이다.

## 2. 같은 판에 넷을 걸어 본다

**셋 다 A 를 되살린다. 되살리는 속도가 다르고, 굳음이 아예 사라지는지도 다르다.**

앞 글의 코드를 그대로 이어 돌린다. `run` 에 붙어 있던 스위치가 여기서 쓰인다.

```python
import random
# 앞 글([어제 띄운 광고만 학습 데이터가 된다](post.html?id=feedback-loop-bias))의
# TRUE·ADS·N·CAP·GENS·allocate·gini·run 을 그대로 쓴다. 그 글의 코드를 먼저 붙여 놓고
# 아래를 이어 붙이면 그대로 돌아간다.


def pad(s, w):   # 한글은 터미널에서 두 칸을 먹는다 — 표를 맞추려고 센다
    return s + ' ' * max(0, w - sum(2 if ord(c) > 0x2000 else 1 for c in s))


def lock_gen(hist):
    """노출을 받는 광고 집합이 마지막으로 바뀐 세대. 8개 전부가 받으면 '없음'."""
    served = [frozenset(x for x in ADS if a[x] > 0) for _, a, _, _ in hist]
    last = 1
    for i in range(1, len(served)):
        if served[i] != served[i - 1]:
            last = i + 1
    return '없음' if len(served[-1]) == 8 else '%d세대' % last


def revived(hist):
    """9931(=A) 이 처음으로 노출 상위 셋에 든 세대."""
    for g, a, _, _ in hist[1:]:
        if 9931 in sorted(ADS, key=lambda x: -a[x])[:3]:
            return '%d세대' % g
    return '없음'


print(pad('처방', 14) + pad('굳음', 10) + pad('9931 복귀', 12)
      + '9931 노출  40세대 클릭  1~5세대 클릭   지니')
for name, kw in [('기본', {}), ('ε탐색 5%', {'mode': 'ε탐색'}),
                 ('낙관 초기값', {'pm': .035, 'pk': 2000}),
                 ('강제슬롯 8%', {'mode': '강제슬롯'})]:
    h, imps, clicks = run(37, **kw)
    first5 = sum(sum(got.values()) for g, a, got, gi in h[:5])
    print(pad(name, 14) + pad(lock_gen(h), 10) + pad(revived(h), 12)
          + '%9d %12d %13d %6.3f'
          % (imps[9931], sum(clicks.values()), first5, h[-1][3]))

rng = random.Random(37)                       # 진짜 CTR 을 처음부터 알았다면
best = allocate(TRUE)                         # 6000·6000·6000·2000 으로 고정 배분
tot = sum(sum(rng.random() < TRUE[ad] for _ in range(500 if g == 1 else best[ad]))
          for g in range(1, GENS + 1) for ad in ADS)
print('참고 — 진짜 CTR 을 알고 배분했다면 40세대 클릭 %d건' % tot)

# 출력:
# 처방          굳음      9931 복귀   9931 노출  40세대 클릭  1~5세대 클릭   지니
# 기본          3세대     없음              500        17350          1813  0.563
# ε탐색 5%      없음      8세대          204375        18541          1844  0.522
# 낙관 초기값   31세대    3세대          222500        18546          1812  0.510
# 강제슬롯 8%   없음      3세대          223300        18515          1914  0.510
# 참고 — 진짜 CTR 을 알고 배분했다면 40세대 클릭 18831건
```

세 처방 다 A 를 되살렸다. 다만 속도가 다르다. 낙관 초기값과 강제 슬롯은 사흘째에 A 를 노출 상위 셋 안으로 올리는데, ε 탐색은 여드레가 걸린다.

이유는 한 세대에 주는 표본 크기다. ε 탐색이 A 에게 주는 몫은 세대당 125건이고 강제 슬롯은 400건이다. 125건짜리 표본으로 1.793% 라는 언 값을 뒤집으려면 여러 세대가 필요하다.

굳음 칸도 갈린다. ε 탐색과 강제 슬롯은 여덟 전부가 매 세대 노출을 받으니 노출 집합이 아예 굳지 않는다. 낙관 초기값은 여전히 매 세대 넷만 띄우지만, 그 넷의 구성이 31세대까지 계속 바뀐다.

낙관 초기값이 자리를 돌리는 방식은 이렇다. 노출을 받은 광고는 추정값이 자기 진짜 값 쪽으로 내려가고, 그러면 아직 덜 본 광고가 위로 올라온다. 시작값을 높게 잡아 둔 덕분에 안 본 광고가 계속 순번을 받는 것이다.

이 판만 보면 클릭 수 차이가 작아 보인다. 기본이 17,350건이고 처방 셋은 18,515건에서 18,546건 사이다. 기준선은 마지막 줄인데, 진짜 클릭률을 처음부터 알고 배분하면 같은 시드에서 18,831건이 나온다.

기본은 그 기준선보다 1,481건 적다. **7.9% 를 잃은 것이다.** 클릭 한 건에 ₩500 이니 40일 동안 ₩740,500 을 흘린 셈이고, 지면 하나 광고군 하나에서만 그렇다.

## 3. 시드 100판으로 다시 본다

**탐색은 대부분의 판에서 조금 손해다. 그리고 소수의 판에서 크게 이득이다.**

시드 하나는 운 한 판이라, 그 한 판으로 예산을 결정하면 안 된다. 시드 100개를 돌려 평균을 보고, 기본이 진짜 상위 셋을 맞힌 판과 틀린 판을 갈라서 본다.

```python
import statistics
# 앞 블록의 run·pad 를 그대로 쓴다. 100판이라 30초 안팎 걸린다.

res, right, out2, out40 = {}, [], [], []
for name, kw in [('기본', {}), ('ε탐색 5%', {'mode': 'ε탐색'}),
                 ('낙관 초기값', {'pm': .035, 'pk': 2000}),
                 ('강제슬롯 8%', {'mode': '강제슬롯'}),
                 ('강제슬롯 5%', {'mode': '강제슬롯', 'slot': 1000})]:
    c40, c05 = [], []
    for seed in range(1, 101):
        h, imps, clicks = run(seed, **kw)
        c40.append(sum(clicks.values()))
        c05.append(sum(sum(got.values()) for g, a, got, gi in h[:5]))
        if name == '기본':      # 마지막 세대 상위 3이 진짜 상위 3과 같은가
            top3 = sorted(ADS, key=lambda x: -h[-1][1][x])[:3]
            right.append(set(top3) == {9931, 9932, 9933})
            out2.append(h[1][1][9931] == 0)      # 2세대에 9931 이 밀려났나
            out40.append(h[-1][1][9931] == 0)    # 40세대에도 여전히 0건인가
    res[name] = (c40, c05)

base = res['기본'][0]
print(pad('처방', 14) + '40세대 클릭  1~5세대 클릭  기본보다 나쁜 판')
for name, (c40, c05) in res.items():
    worse = sum(1 for i in range(100) if c40[i] < base[i])
    print(pad(name, 14) + '%11.0f %13.0f %13d판'
          % (statistics.mean(c40), statistics.mean(c05), worse))

print('9931 이 2세대에 밀려난 판 %d개 · 그중 40세대까지 못 돌아온 판 %d개'
      % (sum(out2), sum(1 for i in range(100) if out2[i] and out40[i])))
eps = res['ε탐색 5%'][0]
ok = [i for i in range(100) if right[i]]
no = [i for i in range(100) if not right[i]]
print('기본이 진짜 상위 3을 맞힌 판 %d개 · 틀린 판 %d개' % (len(ok), len(no)))
print('맞힌 판만: 기본 %.0f → ε탐색 %.0f'
      % (statistics.mean(base[i] for i in ok), statistics.mean(eps[i] for i in ok)))
print('틀린 판만: 기본 %.0f → ε탐색 %.0f'
      % (statistics.mean(base[i] for i in no), statistics.mean(eps[i] for i in no)))

# 출력:
# 처방          40세대 클릭  1~5세대 클릭  기본보다 나쁜 판
# 기본                18513          1938             0판
# ε탐색 5%            18665          1941            38판
# 낙관 초기값         18653          1869            52판
# 강제슬롯 8%         18507          1928            68판
# 강제슬롯 5%         18581          1934            59판
# 9931 이 2세대에 밀려난 판 12개 · 그중 40세대까지 못 돌아온 판 6개
# 기본이 진짜 상위 3을 맞힌 판 60개 · 틀린 판 40개
# 맞힌 판만: 기본 18754 → ε탐색 18738
# 틀린 판만: 기본 18152 → ε탐색 18555
```

먼저 굳음이 얼마나 흔한지부터 보자. 100판 중 12판에서 A 가 둘째 세대에 밀려났고, 그중 6판은 마지막 세대까지 노출이 0건이다. 나머지 6판은 도중에 돌아왔다.

앞 글에서 계산한 조건이 그 갈림을 결정한다. 안에 남은 광고의 진짜 클릭률이 A 의 언 값보다 낮으면 A 가 돌아오고, 높으면 못 돌아온다.

그리고 더 흔한 실패가 따로 있다. **40판에서 상위 셋의 구성이 틀렸다.** 가장 좋은 광고가 끝까지 0건인 극단은 6판뿐이지만, 상위 셋이 어긋나는 일은 40판이다. 굳음은 극단에서만 오는 것이 아니라 늘 조금씩 온다.

이제 매출을 보자. 40세대 누적 클릭의 평균은 기본이 18,513건, ε 탐색 18,665건, 낙관 초기값 18,653건, 강제 슬롯 18,507건이다. 셋의 차이가 크지 않다는 것부터 눈에 들어온다.

처음 5세대만 잘라 보면 이야기가 달라진다. 낙관 초기값이 1,869건이고 기본이 1,938건이라, 시작 닷새 동안은 낙관 쪽이 69건 손해다. 대신 40세대로 늘리면 그 손해를 메우고 앞선다.

**단기 손해와 장기 이득이 갈리는 것이 탐색의 기본 모양이다.** 닷새 만에 끝나는 캠페인이면 낙관 초기값을 켜지 않는 쪽이 낫고, 상시 운영이면 켜는 쪽이 낫다. 같은 처방이 캠페인 길이에 따라 반대 결정이 되는 것이다.

가장 중요한 줄은 마지막 둘이다. 기본이 진짜 상위 셋을 맞힌 60판만 보면 ε 탐색이 16건 손해이고, 틀린 40판만 보면 403건 이득이다.

클릭 한 건에 ₩500 이니 각각 ₩8,000 손해와 ₩201,500 이득이다. 같은 처방인데 어느 판에 걸렸느냐에 따라 부호가 통째로 뒤집힌다.

**탐색은 잘못 굳었을 때만 값을 한다.** 그런데 지금 이 굳음이 옳은지 그른지는 알 수 없다. 그 값을 알려면 탐색을 해 봐야 하기 때문이다. **탐색 예산**은 바로 그 정보에 매기는 값이다.

강제 슬롯은 클릭 수로는 기본을 못 이긴다. 평균이 6건 적고 100판 중 68판에서 진다. 그 값어치는 클릭이 아니라 측정 쪽에 있다. 앞 글 4절을 보면 같은 창에서 역확률 가중의 퍼짐이 ±0.118 에서 ±0.069 로 줄어든다.

:::deep 더 깊이 — 강제 슬롯 예산을 8%에서 5%로 줄이면
예산을 5% 로 줄이면 평균 클릭이 18,581건까지 오르고, 기본에 지는 판도 68판에서 59판으로 준다. 예산을 줄인 만큼 클릭 손해가 줄어든 것이다.

그래도 ε 탐색의 18,665건보다는 낮다. 강제 슬롯은 밀려난 넷에게만 몫을 주는데, 그 넷 중에는 진짜로 나쁜 광고가 섞여 있기 때문이다. 그 광고에 400건을 꽂으면 그만큼 클릭이 깎인다. ε 탐색은 같은 몫을 여덟에 흩뿌리므로 나쁜 광고에게 가는 몫이 125건으로 작다.

예산을 얼마로 잡을지는 이 손익과 측정 정확도를 같이 놓고 결정한다. 이 글은 8% 와 5% 두 값만 재 봤다.
:::

정리하면 고르는 기준은 아래와 같다. 클릭만 보면 ε 탐색, 측정까지 보면 강제 슬롯, 상시 운영이면 낙관 초기값 쪽이다.

| 처방 | 클릭으로 보면 | 굳음 해소 | 언제 고르나 |
|---|---|---|---|
| ε 탐색 5% | 100판 평균 1위 | 아예 안 굳는다 | 클릭이 최우선일 때 |
| 낙관 초기값 | 초반 손해, 나중에 회복 | 31세대까지 자리가 돈다 | 상시 운영이라 초반 손해를 견딜 때 |
| 강제 슬롯 8% | 100판 중 68판에서 손해 | 아예 안 굳는다 | 그 로그로 예산을 결정해야 할 때 |
| 역확률 가중 | 노출을 안 쓰니 손해 0 | 못 푼다 | 위 셋 중 하나를 켠 다음에 |

**마지막 줄이 순서를 말해 준다.** 역확률 가중은 단독으로 쓰면 아무것도 못 고치고, 탐색을 켠 뒤에 얹어야 값을 한다. 탐색이 성향점수를 만들고, 그 성향점수가 역확률 가중을 가능하게 하기 때문이다.

## 한눈 정리

| 무엇 | 이 글의 숫자 | 어디서 |
|---|---|---|
| 기본 고리가 잃은 클릭 | 18,831건 대비 17,350건 | 2절 |
| ε 탐색이 A 를 상위 셋에 올린 세대 | 여드레째 | 2절 |
| 강제 슬롯이 A 를 상위 셋에 올린 세대 | 사흘째 | 2절 |
| 한 세대에 A 가 받는 몫 | ε 탐색 125건 · 강제 슬롯 400건 | 1절 |
| 100판 중 A 가 40세대까지 못 돌아온 판 | 6판 | 3절 |
| 100판 중 상위 셋 구성이 틀린 판 | 40판 | 3절 |
| 옳게 굳은 판에서 ε 탐색의 값 | 16건 손해 (₩8,000) | 3절 |
| 잘못 굳은 판에서 ε 탐색의 값 | 403건 이득 (₩201,500) | 3절 |
| 낙관 초기값의 초반 손해 | 처음 5세대에 1,869건 대 1,938건 | 3절 |

## 헷갈리기 쉬운 점

- **탐색 예산은 매출을 사는 돈이 아니라 정보를 사는 돈이다.** 이미 옳게 굳은 판에서는 ε 탐색이 그냥 손해였다. 옳은지 그른지 모르기 때문에 내는 값이다.
- **평균만 보면 처방들이 다 비슷해 보인다.** 100판 평균 차이는 작지만, 잘못 굳은 판만 갈라 보면 403건이 갈린다. 평균은 두 세계를 섞어 놓은 값이다.
- **강제 슬롯이 클릭으로 지는 것은 설계상 그렇다.** 밀려난 넷에게만 몰아 주니 그중 진짜 나쁜 광고에도 같은 몫이 꽂힌다. 대신 그 몫이 측정 정확도로 돌아온다.
- **낙관 초기값의 손해는 앞쪽에 몰려 있다.** 처음 다섯 세대는 뒤지고 마지막에 앞선다. 캠페인이 짧으면 이 처방은 손해로만 끝난다.
- **역확률 가중은 처방이라기보다 계산법이다.** 노출을 하나도 안 쓰니 매출 손해가 없는 대신, 로그에 없는 광고를 되살리지도 못한다.
- **여기 숫자는 광고당 상한이 있는 판의 값이다.** 상한이 다르면 노출 자리 수가 달라지고, 그러면 몇 퍼센트를 떼어야 하는지도 달라진다.
