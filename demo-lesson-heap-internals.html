힙의 내부: 부모와 자식 규칙, heappush, heappop 의 두 방식

힙 리스트 안쪽에서 일어나는 일을 한 단계씩 따라갑니다. 첫 탭은 리스트의 칸이 부모와 자식이 되는 규칙, 둘째 탭은 heappush 가 새 값을 올리는 자리 이동, 셋째 탭은 맨 앞 값을 꺼낸 뒤 마지막 값을 내려보내는 교과서 방식 heappop, 넷째 탭은 빈칸을 잎까지 내리는 CPython 방식 heappop 입니다.

한 줄 요약
힙 리스트는 부모 칸의 값이 자식 칸의 값보다 크지 않다는 규칙(힙 규칙) 하나로 정해지고 heappush 와 heappop 은 이 규칙을 되살리는 자리 이동입니다. 값이 모두 다른 12칸 [1, 2, 7, 3, 6, 9, 8, 15, 4, 10, 12, 11] 에서 맨 앞 값을 한 번 꺼낼 때 비교는 교과서 방식이 6번, CPython 방식이 4번이고 남는 리스트는 [2, 3, 7, 4, 6, 9, 8, 15, 11, 10, 12] 로 같습니다.
보여 주는 장면과외에서 지훈 씨가 물은 힙 안쪽 장면 넷입니다. 리스트의 i번 칸이 어떻게 트리의 부모와 자식이 되는지, 부모와 자식만 정렬되어 있는데 왜 맨 앞 값이 가장 작은지, heappush 가 새 값을 어디까지 올리는지, heappop 에서 맨 앞 값을 꺼낸 뒤 비는 칸을 어떻게 메우는지를 봅니다. 마지막 장면은 두 가지입니다. 교과서 방식은 마지막 값을 맨 앞에 두고 내리고 CPython 의 heapq 는 빈칸을 잎까지 내린 뒤 마지막 값으로 채워 올립니다. 입력은 값 3개에서 12개까지라 단계를 모두 따라갈 수 있습니다. 크기 K 힙과 heapify 로 푸는 두 풀이는 힙과 Top K 데모에서 이어서 봅니다.
목적첫 탭에서는 힙 규칙이 부모와 자식 사이에만 있고 층이 다른 두 칸의 순서는 정하지 않는다는 것, 그래도 두 번째로 작은 값은 루트의 두 자식 가운데 하나라는 것을 확인합니다. 둘째 탭에서는 새 값이 부모보다 작은 동안만 올라가서 비교가 값마다 다르다는 것을 확인합니다. 셋째와 넷째 탭에서는 같은 입력을 두 방식으로 꺼내 남는 리스트가 같다는 것과 비교 횟수가 다르다는 것을 확인합니다. 입력은 아홉 가지입니다. 첫 탭은 최소 힙 [10, 50, 20, 60, 70, 25, 30], 최대 힙 [90, 80, 75, 50, 60, 70], 규칙을 어기는 [50, 90, 10] 이고 둘째 탭은 넣는 순서 [40, 10, 30, 5], [50, 10, 90, 30, 70], 부호를 뒤집은 [-50, -10, -90, -30, -70] 입니다. 셋째와 넷째 탭은 [10, 20, 15, 40, 50, 30], 빈칸이 잎에 닿은 뒤 올라가는 [10, 15, 20, 40, 50, 30], 값 12개 [1, 2, 7, 3, 6, 9, 8, 15, 4, 10, 12, 11] 입니다.
결과 읽는 법결과 칸은 첫 탭에서 규칙을 지키는 쌍의 수와 두 번째 값, 둘째 탭에서 넣은 뒤의 리스트, 셋째와 넷째 탭에서 꺼낸 값과 남은 리스트입니다. 아랫줄에는 어긴 쌍, 값마다의 비교 횟수, 한 번 꺼낼 때의 비교 횟수가 나옵니다. 보드의 위쪽은 리스트이고 아래쪽은 같은 리스트를 트리로 그린 것이며 노드 아래 작은 숫자가 리스트의 인덱스입니다. 파란 테두리 칸이 지금 보는 칸, 연한 파란 칸이 넣은 값이나 움직이는 값, 진한 파란 칸이 답, 붉은 칸이 규칙을 어긴 자식입니다. 점선 칸은 빈칸입니다. 상태 칸의 칩은 첫 탭에서 부모 값과 자식 값을 실제 크기 관계로 적고 붉은 칩이 규칙을 어긴 쌍입니다. 두 heappop 탭에서 붉은 계열 칩은 꺼낸 값입니다. 파이썬 코드와 비용은 글에서 이어서 봅니다.
    따라 하는 순서
  1. 탭 부모와 자식 규칙에서 입력은 [10, 50, 20, 60, 70, 25, 30] 입니다. 「다음 쌍」을 한 번 누르면 1번 칸 50과 부모 0번 칸 10을 비교합니다. 여섯 번 누르면 부모와 자식 6쌍을 모두 확인해 단계 6 / 8 이 됩니다. 일곱 번째에는 2층의 50이 3층의 25보다 크지만 둘은 부모와 자식이 아니라는 것을 보이고 여덟 번째에는 루트의 두 자식 50, 20 가운데 작은 20이 진한 파란색이 됩니다. 결과 칸에 「부모와 자식 6쌍 모두 부모 ≤ 자식」이 나옵니다.
  2. 같은 탭에서 입력 목록의 [90, 80, 75, 50, 60, 70] 최대 힙을 고르고 「끝까지」를 누르면 「5쌍 모두 부모 ≥ 자식」과 두 번째로 큰 값 80이 나옵니다. [50, 90, 10] 을 고르고 「끝까지」를 누르면 2번 칸 10이 붉게 칠해지고 결과 칸에 「2쌍 가운데 1쌍이 규칙을 어깁니다」가 나옵니다.
  3. 탭 heappush 의 자리 이동에서 입력은 넣는 순서 [40, 10, 30, 5] 입니다. 「다음 값」을 세 번 누르면 [10, 40, 30] 이 되고 네 번 누르면 5가 3번 칸에서 1번 칸을 거쳐 0번 칸까지 올라가 [5, 10, 30, 40] 이 되며 단계 12 / 12 입니다. 결과 칸 아랫줄에 「비교 0 + 1 + 1 + 2 = 4번」이 나옵니다. 「한 칸」을 누르면 붙이기, 부모와 비교, 자리 잡기가 따로 넘어갑니다.
  4. 탭 교과서 방식 heappop에서 입력은 [10, 20, 15, 40, 50, 30] 입니다. 「다음 층」을 한 번 누르면 맨 앞 값 10을 꺼내고 마지막 값 30을 0번 칸에 둔 [30, 20, 15, 40, 50] 이 되어 단계 3 / 5 입니다. 두 번째에는 두 자식 20과 15 가운데 작은 15와 30을 바꿔 [15, 20, 30, 40, 50] 이 되고 세 번째에는 2번 칸의 30에 자식이 없어 멈춥니다. 결과 칸에 「꺼낸 값 10, 남은 리스트 [15, 20, 30, 40, 50]」이 나옵니다.
  5. 탭 CPython 방식 heappop에서 입력 [10, 15, 20, 40, 50, 30] 을 고릅니다. 「다음 층」을 세 번 누르면 단계 4 / 8 에서 15와 40을 차례로 위로 올려 [15, 40, 20, 빈칸, 50] 이 되고 빈칸이 3번 칸 잎에 닿습니다. 네 번째에는 빈칸을 30으로 채우고 부모 40, 15와 비교해 [15, 30, 20, 40, 50] 이 됩니다. 결과 아랫줄에 「비교 4번」이 나옵니다. 같은 입력을 교과서 방식 탭에서 보면 남은 리스트와 비교 4번이 같습니다.
  6. 두 탭 모두에서 입력 목록의 값 12개 [1, 2, 7, 3, 6, 9, 8, 15, 4, 10, 12, 11] 을 고르고 「끝까지」를 누릅니다. 두 탭의 남은 리스트는 [2, 3, 7, 4, 6, 9, 8, 15, 11, 10, 12] 로 같고 비교는 교과서 방식이 6번, CPython 방식이 4번입니다. 탭이나 입력을 바꾸면 처음 상태로 돌아갑니다.
