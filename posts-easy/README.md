# posts-easy

글의 쉬운 판을 모아 두는 폴더입니다. 원래 글과 나란히 비교하려고 따로 둡니다.

- 파일 이름은 `posts/<id>.md` 와 같은 `<id>.md` 입니다. 같은 id 를 `js/easy-posts.js` 의 `EASY_POST_IDS` 에 적어야 글 페이지에 링크가 생깁니다.
- `post.html?id=<id>&v=easy` 로 열며, 일반 글과 같은 렌더러를 씁니다.
- 코드 블록과 `# 출력:` 에 찍힌 값은 원래 글과 글자까지 같아야 합니다. 바꾸는 것은 설명 문장뿐입니다.
- 글 목록, 검색 색인, 사이트맵, 피드와 `posts/*.md` 를 도는 검사는 이 폴더를 보지 않습니다.
