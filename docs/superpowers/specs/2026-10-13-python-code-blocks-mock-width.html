블록 모양 고르기 2

B 를 실제 글 폭에 넣으면, 긴 줄은 어떻게 할까요?

B 는 왼쪽에 설명 칸이 생기는 만큼 코드 칸이 좁아집니다. 1440 화면에서 코드 칸이 지금 104자에서 74자로 줄어듭니다.

두 시안 모두 두 탑 학습 글의 PyTorch 블록입니다. 이 글에서 긴 줄이 가장 많은 블록입니다. 1440 화면의 글 칸 폭(1053px)으로 그렸습니다.

두 시안에 같이 넣은 규칙이 셋 있습니다.

  • 설명 칸은 첫 시안의 300px 에서 260px 로 줄였습니다.
  • 줄 끝 주석은 자리가 있으면 줄 끝에 세로로 맞춰 두고, 자리가 없으면 그 줄 바로 아래로 내립니다.
  • 코드가 칸보다 길면 그 줄만 접습니다. 접힌 줄 왼쪽에 파란 세로 막대가 붙습니다.

코드 블록이 글 문단과 같은 폭입니다. 지금 블로그와 같습니다.

1~8절의 계산을 PyTorch 로 옮긴 것입니다. 광고 200개와 회원 정보를 가짜로 만들어 바로 돌아가게 했고, 인기는 순위의 역수로 쏠리게 두었습니다.

import torch
import torch.nn as nn
import torch.nn.functional as F
1가짜 광고 200개를 만든다

광고마다 정보 16개와 인기를 둔다. 인기가 앞 순위에 쏠려야 인기 보정이 하는 일이 보인다.

torch.manual_seed(0)
N_ADS, D_IN, D = 200, 16, 32광고 수, 입력 차원, 벡터 길이 (가상 값)
ad_x = torch.randn(N_ADS, D_IN)광고 정보
pop = 1 / torch.arange(1, N_ADS + 1).float()인기를 순위의 역수로 쏠리게 둔다
pop = pop / pop.sum()광고별 클릭 점유율 q
W = torch.randn(D_IN, D_IN) / 4회원 정보와 광고 정보를 잇는 숨은 관계
2클릭 n건을 뽑는다

인기대로 광고를 뽑고, 그 광고를 누를 법한 회원 정보를 붙인다. 한 건이 양성 쌍 하나다.

def clicks(n):
ad = torch.multinomial(pop, n, replacement=True)누른 광고
member_x = ad_x[ad] @ W + 1.0 * torch.randn(n, D_IN)그 광고를 누를 법한 회원 정보
return member_x, ad
3타워 하나의 모양

정보 16개를 64개를 거쳐 벡터 32개로 바꾼다. 회원 타워와 광고 타워가 이 모양을 하나씩 따로 쓴다.

class Tower(nn.Module):
def __init__(self):
super().__init__()
self.mlp = nn.Sequential(nn.Linear(D_IN, 64), nn.ReLU(), nn.Linear(64, D))
def forward(self, x):
return F.normalize(self.mlp(x), dim=-1)길이를 1로 맞춘다
4두 타워를 300번 학습한다

배치 256건의 점수표에 인기 보정과 accidental hit 제거를 넣고, 대각선을 정답으로 손실을 줄인다. 100번마다 손실을 찍는다.

member_tower, ad_tower = Tower(), Tower()
opt = torch.optim.Adam([*member_tower.parameters(), *ad_tower.parameters()], lr=3e-3)
tau, log_q, B = 0.1, pop.log(), 256
for step in range(301):
member_x, ad = clicks(B)클릭 B건 = 양성 쌍 B줄
logits = member_tower(member_x) @ ad_tower(ad_x[ad]).T / tau(B, B) 점수표
logits = logits - log_q[ad][None, :]인기 광고 보정. 학습 때만
same = (ad[:, None] == ad[None, :]) & ~torch.eye(B, dtype=torch.bool)
logits = logits.masked_fill(same, float('-inf'))accidental hit 제거
loss = F.cross_entropy(logits, torch.arange(B))줄마다 정답은 대각선
opt.zero_grad()
loss.backward()두 타워를 같이 고친다
opt.step()
if step % 100 == 0:
print(f'step {step:3d} 손실 {loss.item():.3f}')
5학습에 안 쓴 클릭으로 잰다

누른 광고가 상위 10개 안에 드는지 보고, 클릭 많은 순 10개를 모두에게 준 기준선과 비교한다.

with torch.no_grad():학습에 안 쓴 클릭 2,000건으로 평가
member_x, ad = clicks(2000)
top10 = (member_tower(member_x) @ ad_tower(ad_x).T).topk(10).indices보정 없이 내적 그대로
recall = (top10 == ad[:, None]).any(1).float().mean()
base = torch.isin(ad, pop.topk(10).indices).float().mean()클릭 많은 순 10개
print(f'Recall@10 two-tower {recall:.3f} 클릭 많은 순 {base:.3f}')

가짜 광고 200개로 두 타워를 300번 학습하고, 학습에 안 쓴 클릭 2,000건으로 Recall@10 을 잰다.
import torch
import torch.nn as nn
import torch.nn.functional as F
1가짜 광고 200개를 만든다

광고마다 정보 16개와 인기를 둔다. 인기가 앞 순위에 쏠려야 인기 보정이 하는 일이 보인다.

torch.manual_seed(0)
N_ADS, D_IN, D = 200, 16, 32광고 수, 입력 차원, 벡터 길이 (가상 값)
ad_x = torch.randn(N_ADS, D_IN)광고 정보
pop = 1 / torch.arange(1, N_ADS + 1).float()인기를 순위의 역수로 쏠리게 둔다
pop = pop / pop.sum()광고별 클릭 점유율 q
W = torch.randn(D_IN, D_IN) / 4회원 정보와 광고 정보를 잇는 숨은 관계
2클릭 n건을 뽑는다

인기대로 광고를 뽑고, 그 광고를 누를 법한 회원 정보를 붙인다. 한 건이 양성 쌍 하나다.

def clicks(n):
ad = torch.multinomial(pop, n, replacement=True)누른 광고
member_x = ad_x[ad] @ W + 1.0 * torch.randn(n, D_IN)그 광고를 누를 법한 회원 정보
return member_x, ad
3타워 하나의 모양

정보 16개를 64개를 거쳐 벡터 32개로 바꾼다. 회원 타워와 광고 타워가 이 모양을 하나씩 따로 쓴다.

class Tower(nn.Module):
def __init__(self):
super().__init__()
self.mlp = nn.Sequential(nn.Linear(D_IN, 64), nn.ReLU(), nn.Linear(64, D))
def forward(self, x):
return F.normalize(self.mlp(x), dim=-1)길이를 1로 맞춘다
4두 타워를 300번 학습한다

배치 256건의 점수표에 인기 보정과 accidental hit 제거를 넣고, 대각선을 정답으로 손실을 줄인다. 100번마다 손실을 찍는다.

member_tower, ad_tower = Tower(), Tower()
opt = torch.optim.Adam([*member_tower.parameters(), *ad_tower.parameters()], lr=3e-3)
tau, log_q, B = 0.1, pop.log(), 256
for step in range(301):
member_x, ad = clicks(B)클릭 B건 = 양성 쌍 B줄
logits = member_tower(member_x) @ ad_tower(ad_x[ad]).T / tau(B, B) 점수표
logits = logits - log_q[ad][None, :]인기 광고 보정. 학습 때만
same = (ad[:, None] == ad[None, :]) & ~torch.eye(B, dtype=torch.bool)
logits = logits.masked_fill(same, float('-inf'))accidental hit 제거
loss = F.cross_entropy(logits, torch.arange(B))줄마다 정답은 대각선
opt.zero_grad()
loss.backward()두 타워를 같이 고친다
opt.step()
if step % 100 == 0:
print(f'step {step:3d} 손실 {loss.item():.3f}')
5학습에 안 쓴 클릭으로 잰다

누른 광고가 상위 10개 안에 드는지 보고, 클릭 많은 순 10개를 모두에게 준 기준선과 비교한다.

with torch.no_grad():학습에 안 쓴 클릭 2,000건으로 평가
member_x, ad = clicks(2000)
top10 = (member_tower(member_x) @ ad_tower(ad_x).T).topk(10).indices보정 없이 내적 그대로
recall = (top10 == ad[:, None]).any(1).float().mean()
base = torch.isin(ad, pop.topk(10).indices).float().mean()클릭 많은 순 10개
print(f'Recall@10 two-tower {recall:.3f} 클릭 많은 순 {base:.3f}')
