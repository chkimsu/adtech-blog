하둡 카드 여섯 장

카드 하나가 개념 하나입니다. 서버 아이콘 하나가 서버 한 대이고, 움직이는 점이 데이터나 요청이 가는 방향입니다. 주소와 숫자는 설명용 예시입니다.

파랑 = 저장 (HDFS) 벽돌색 = 계산 (YARN) 먹색 = Hive 서버 회색 = ZooKeeper 점 = 지금 가고 있는 데이터, 요청

CLUSTER

클러스터 = 서버 여러 대, 역할은 프로그램

위 줄은 역할이 하나씩인 서버들입니다. 아래 줄 워커는 한 대에 저장(DN)과 계산(NM) 두 역할이 같이 있습니다.

HDFS

파일을 조각내어 여러 상자에 세 벌씩

NameNode 는 목록만 듭니다. 조각은 DataNode 에 세 벌씩 있어서 한 대가 꺼져도 파일은 살아 있습니다.

YARN

계산할 자리를 나눠 줍니다

큐는 서버가 아닙니다. ResourceManager 안에서 자원을 나누는 줄입니다. 계산 조각은 데이터 조각이 있는 워커로 갑니다.

HIVE

쿼리 한 건이 지나는 길

내가 직접 말하는 상대는 HiveServer2 하나입니다. 그 서버가 Metastore 에 위치를 묻고, YARN 에서 자원을 받아, 워커에서 세고, 결과를 돌려줍니다.

ZOOKEEPER

살아 있는 서버 목록을 다섯 벌

HiveServer2 는 켜질 때 여기 등록합니다. 나는 ZooKeeper 에 「어디로 가?」를 묻고 답을 받아 그 서버로 갑니다.

JDBC 주소

한 줄이 가리키는 곳

주소에 적힌 다섯 서버는 ZooKeeper 입니다. 계정과 http 는 HiveServer2 에, 큐 이름 하나만 YARN 에 갑니다.

현업에서는 이렇게 씁니다

  • 카드를 누르면 위 해설 칸에 그 카드가 놓친 한 가지가 더 나옵니다.
  • 같은 그림을 상자 그림으로 보고 싶으면 하둡 상자 그림 여섯 장이 있습니다. 층이 나뉘는 구조는 그쪽이 더 잘 보입니다.
  • 글로 이어 읽으려면 하둡과 Hive 글에 이 카드들이 절마다 한 장씩 들어 있습니다.
